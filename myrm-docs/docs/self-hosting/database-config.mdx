# Database Configuration

Myrm keeps all of its data in one data directory: `MYRM_DATA_DIR` (default `~/.myrm`). No external database or vector service is needed.

| Path | Contents |
|------|----------|
| `data.db` | Primary SQLite database |
| `qdrant/` | Embedded vector store used by memory search |
| `checkpoints.db` | Agent checkpoints |
| `memory/` | Memory content |

Only one running copy of Myrm can use a data directory at a time, because the embedded vector store locks its folder. A second copy that cannot open it keeps running, but it does not save new memories permanently and shows a warning in the app.

## Graph store (optional)

`DATABASE_URL` points to an optional Apache AGE (PostgreSQL) graph store. Leave it empty to keep the graph in SQLite inside the data directory.

## Backup

Stop Myrm, then copy the whole data directory:

```bash
cp -R "${MYRM_DATA_DIR:-$HOME/.myrm}" "./backups/myrm-$(date +%Y%m%d)"
```
