# Upgrade Guide

## Docker Compose

```bash
cd myrm
git pull
docker compose pull
docker compose up -d
```

## Tauri Desktop

Download the latest release from [GitHub Releases](https://github.com/myrm-ai/myrm/releases) and install over the existing version.

## Database Migrations

Database migrations run automatically on startup. No manual intervention required.

## Breaking Changes

Check the [CHANGELOG](https://github.com/myrm-ai/myrm/blob/main/CHANGELOG.md) for breaking changes before upgrading major versions.
