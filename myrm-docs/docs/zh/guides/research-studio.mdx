# 研究工作台

研究工作台是一个**三栏并列界面**，让你在同一个视图中整理研究资料、与 AI 对话、预览生成的工件。支持**本地 WebUI**、**Tauri 桌面端**和**云托管部署**。

## 布局

| 栏位 | 用途 |
|------|------|
| **左栏 — 资料池** | 从知识库搜索概念、上传文件，勾选作为研究上下文。 |
| **中栏 — 对话** | 与任意已配置的智能体对话，选中的资料自动注入上下文。 |
| **右栏 — 产出** | 预览生成的工件（文档、演示稿、报告），支持下载和存入知识库。 |

在移动设备上（视口宽度 ≤ 768px），三栏自动切换为 **Tab 标签导航**。

## 打开研究工作台

在侧边栏点击"研究工作台"或直接访问 **/research**。

## 添加研究资料

### 从知识库添加

1. 点击资料池顶部的**从知识库**按钮。
2. 输入关键词搜索知识库概念。
3. 点击概念名称即可添加，已添加的概念自动标记为"已添加"。

### 上传文件

1. 点击资料池顶部的**上传**按钮。
2. 选择文件（支持 PDF、DOCX、TXT、MD、CSV、XLSX、PPTX）。
3. 上传的文件出现在资料池中，可以勾选使用。

## 勾选与取消

每个资料前有 **复选框**。被选中的资料会自动以 `@wiki_concept` 或 `@wiki_raw_file` 引用的方式注入 AI 对话上下文。

- **全选 / 取消全选** — 一键切换所有资料。
- **单项切换** — 点击资料行即可切换选中状态。

只有知识库类型的引用由同步机制管理。你在聊天输入框手动添加的其他 `@` 引用（如 `@file.pdf`）会被保留。

## 带上下文对话

中栏是完整的聊天界面。选中资料池中的资料后，它们的内容会被注入到下一条消息中。智能体可以引用和推理所有选中的资料。

可以使用内置的 `builtin-researcher` 研究智能体，或任何自定义智能体。

## 查看和导出工件

当智能体生成工件（报告、演示稿、文档）时，它们会出现在右栏：

- **预览** — 渲染的内容，支持语法高亮和格式化。
- **下载** — 保存工件到本地。
- **存入知识库** — 将工件持久化到知识库中，方便后续引用。

## 响应式设计

工作台自动适配屏幕尺寸：

| 屏幕 | 布局 |
|------|------|
| 桌面端 (> 768px) | 三栏可拖拽调整宽度。 |
| 移动端 (≤ 768px) | Tab 标签导航：资料、对话、产出。 |
