# 研究工作台

研究工作台是一个**三栏并列界面**，让你在同一个视图中整理研究资料、与 AI 对话、预览生成的工件。支持**本地 WebUI**、**Tauri 桌面端**和**云托管部署**。

## 布局

| 栏位 | 用途 |
|------|------|
| **左栏 — 资料池** | 从知识库搜索概念、上传文件，勾选作为研究上下文。 |
| **中栏 — 对话** | 与任意已配置的智能体对话，选中的资料自动注入上下文。 |
| **右栏 — 产出** | 预览生成的工件（文档、演示稿、报告），支持下载和存入知识库。 |

在移动设备上（视口宽度 ≤ 768px），三栏自动切换为 **Tab 标签导航**。

## 打开研究工作台

在侧边栏点击"研究工作台"或直接访问 **/research**。

## 添加研究资料

### 从知识库添加

1. 点击资料池顶部的**从知识库**按钮。
2. 输入关键词搜索知识库概念。
3. 点击概念名称即可添加，已添加的概念自动标记为"已添加"。

### 上传文件

1. 点击资料池顶部的**上传**按钮。
2. 选择文件（支持 PDF、DOCX、TXT、MD、CSV、XLSX、PPTX）— 一次最多 20 个文件，单文件最大 50MB。
3. 上传的文件出现在资料池中，可以勾选使用。
4. 大文档（> 100KB）会自动入库知识库进行智能 RAG 检索，节省 LLM token。
5. 重复文件通过 SHA-256 哈希自动检测并跳过。

## 勾选与取消

每个资料前有 **复选框**。被选中的资料会自动以 `@wiki_concept` 或 `@wiki_raw_file` 引用的方式注入 AI 对话上下文。

- **全选 / 取消全选** — 一键切换所有资料。
- **单项切换** — 点击资料行即可切换选中状态。

只有知识库类型的引用由同步机制管理。你在聊天输入框手动添加的其他 `@` 引用（如 `@file.pdf`）会被保留。

## 带上下文对话

中栏是完整的聊天界面。选中资料池中的资料后，它们的内容会被注入到下一条消息中。智能体可以引用和推理所有选中的资料。

可以使用内置的 `builtin-researcher` 研究智能体，或任何自定义智能体。

## 查看和导出工件

当智能体生成工件（报告、演示稿、文档、思维导图、音频等）时，它们会出现在右栏：

- **预览** — 渲染的内容，支持语法高亮、可交互图表和媒体播放。
- **下载** — 保存工件到本地。
- **存入知识库** — 将工件持久化到知识库中，方便后续引用。
- **Tab 切换** — 多个工件可通过标签页切换查看。

### 支持的输出类型

| 类型 | 渲染方式 | 示例提示词 |
|------|----------|------------|
| **思维导图** | 可交互 Mermaid SVG — 缩放/全屏/SVG下载/图例过滤 | "画一个关键发现的思维导图" |
| **音频** | 内置音频播放器 | "把摘要读出来" |
| **文档** | 格式化 Markdown + 代码高亮 | "写一份研究报告" |
| **演示稿** | PPTX 预览和下载 | "用这篇报告做 PPT" |
| **HTML** | 沙箱化 iframe 预览 | "做一个交互式仪表板" |
| **图表** | Mermaid 图表（流程图/序列图/甘特图等 13+ 种） | "画一个时间线图" |
| **代码** | 语法高亮 + 语言自动检测 | "写一个 Python 分析脚本" |
| **表格** | CSV/Excel 表格视图 | "导出数据为 CSV" |

## 研究→笔记→演示稿 全链路闭环

研究工作台支持从研究到交付的完整工作流，无需离开界面：

1. **研究** — 在资料池中勾选材料，让智能体进行深度研究。`builtin-researcher` 智能体支持 HITL 计划确认，你可以在执行前审阅和编辑研究计划。
2. **存为笔记** — 当智能体产出报告后，点击消息操作栏上的**保存到知识库**按钮。笔记保存时附带溯源信息（来源对话、消息 ID、时间戳），方便追溯到原始对话。
3. **编辑** — 在知识库概念面板中打开保存的笔记，直接编辑 Markdown 内容。
4. **生成演示稿** — 在对话中说"用这篇报告做一份 PPT"。`office-document` 技能使用 `python-pptx` 在沙箱环境中生成完全可编辑的 `.pptx` 文件。智能体可自由控制每页的内容、布局、图表和样式——不受固定模板限制。
5. **下载** — 生成的演示稿出现在右栏产出区，直接下载即可。

这种对话式工作流**比固化管线引擎更灵活**：你可以在任意步骤介入、要求修改特定章节、更换演示风格、或从任意节点重新开始——全程自然语言交互。

## 多文档跨篇分析

将多个文件上传到资料池（或导入知识库），全选后提出分析型问题，例如：

- "这些报告有哪些共识性观点？"
- "这些文档之间有哪些矛盾之处？"
- "「AI 将取代 30% 的岗位」这句话最初是哪份报告说的？"

智能体会读取所有选中的文档，识别共识、矛盾和引语归属，生成结构化分析报告。核心特性：

- **引用可点击跳转** — 每条归因引语通过 Citation Source Jump 链接到原文段落，点击即可查看高亮的原始上下文。
- **并行分析** — 面对大量文档时，智能体可将各文档的分析并行委派给子 Agent，再综合结果。
- **信息完整性保障** — 内置完整性规则确保所有论断基于证据，来源之间的矛盾会被明确标注。
- **灵活分析角度** — 没有预设分析模板。你可以提问任何角度——趋势、时间线、情感、风险因素——智能体会动态调整分析策略。

## 响应式设计

工作台自动适配屏幕尺寸：

| 屏幕 | 布局 |
|------|------|
| 桌面端 (> 768px) | 三栏可拖拽调整宽度。 |
| 移动端 (≤ 768px) | Tab 标签导航：资料、对话、产出。 |
