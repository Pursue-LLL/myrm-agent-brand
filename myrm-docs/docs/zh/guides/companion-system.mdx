# AI 伴侣系统

伴侣系统将 Agent 变为具备个性、情感感知与游戏化成长的虚拟伴侣。

## 特性

<CardGroup cols={2}>
  <Card title="15 物种" icon="paw">
    15 种伴侣物种，各有独特特质与进化路径。
  </Card>
  <Card title="情感感知" icon="heart">
    伴侣感知对话语气并相应调整回应。
  </Card>
  <Card title="成长系统" icon="arrow-up">
    通过互动升级，解锁新能力与性格特质。
  </Card>
  <Card title="自适应风格" icon="comment">
    沟通风格随关系历史与偏好演化。
  </Card>
</CardGroup>

## 配置

1. 进入 **设置 > 伴侣**
2. 选择伴侣物种
3. 自定义性格特质
4. 开启情感感知开关

## 工作原理

伴侣系统为 Agent 增加情感智能层：

- 分析对话情感与上下文
- 调整语气、用词与参与度
- 追踪关系进展
- 长任务中鼓励、完成时庆祝

伴侣人格作为系统提示词一部分注入，兼容所有提示词模式与模型配置。
