## 配置

1. 进入 **设置 > 伴侣** — 伴侣系统默认开启
2. 从 15 种物种和 9 种帽子中选择
3. 切换到 **画廊** 标签页浏览 petdex.dev 社区精灵图 — 搜索、预览、一键安装
4. 在 chip 行管理已安装宠物 — 切换激活精灵或通过菜单移除
5. 聊天输入 `/pet` 随时打开 Pet Palette，零 LLM 消耗
6. 选中的精灵图配置通过服务端 API 自动跨设备同步
7. 伴侣自动关联当前活跃 Agent 的外观

## 工作原理

伴侣系统在两个视觉层面运作：

- **SVG 层**（默认）：轻量图标渲染，嵌入聊天输入区附近。自动反映活跃 Agent 的物种和帽子。
- **精灵层**（可选）：Canvas 2D 动画引擎，支持 Codex 8×9 标准精灵图（1536×1872px）。Tauri 桌面端默认主窗嵌入，可 **Pop Out** 至 OS 外置窗（主窗 SSOT + 傀儡窗 event 同步）；WebUI 为页内可拖拽覆盖层。`resolvePetSheetRow()` 自动检测 Codex（9 行）/ Legacy（8 行）布局，映射 **Hermes 对齐的 7 态**。状态气泡 **仅在外置桌面窗** 显示。

精灵状态机 = **SSE 工作流事件** + **GUI 阻塞信号**：

- **工作流 SSE**（`stepKeyToPetEvent`）：规划→review、执行→run、失败→failed、里程碑→jump/review（transient）
- **HITL 阻塞**（`deriveBlockedOnUser` 聚合审批/澄清/桌面/浏览器 store）：**waiting** — 需你操作时优先于 run/wave；Codex 第 6 行（Legacy 回退 idle）
- **流式活跃**：busy→review；回合结束→wave（未被阻塞时）

所有状态通过 Zustand + localStorage 管理。伴侣配置通过 `/companion/config` API 同步到服务端。
