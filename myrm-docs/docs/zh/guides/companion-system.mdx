# AI 伴侣系统

伴侣系统将 Agent 变为具备个性、情感感知与游戏化成长的虚拟伴侣。

## 配置

1. 进入 **设置 > 伴侣** 启用系统
2. 从 15 种物种和 9 种帽子中选择
3. 切换到 **画廊** 标签页浏览 petdex.dev 社区精灵图 — 搜索、预览、一键安装
4. 选中的精灵图配置通过服务端 API 自动跨设备同步
5. 伴侣自动关联当前活跃 Agent 的外观

## 工作原理

伴侣系统在两个视觉层面运作：

- **SVG 层**（默认）：轻量图标渲染，嵌入聊天输入区附近。自动反映活跃 Agent 的物种和帽子。
- **精灵层**（可选）：Canvas 2D 动画引擎，支持 Codex 8×9 标准精灵图（1536×1872px）。`resolveAnimRow` 引擎自动检测行数并通过别名映射确保所有社区精灵图正确播放。桌面端渲染为原生透明窗口，WebUI 渲染为可拖拽覆盖层。

状态机从 Agent 的 SSE 流接收事件并映射到动画：

- `workflow_planning` → 思考（sticky）
- `workflow_execution` → 运行（sticky）
- `approval_waiting` → 挥手（sticky）
- `consensus_reference_done` → 庆祝（transient）
- `model_failover` → 失败（transient）

所有状态通过 Zustand + localStorage 管理。伴侣配置通过 `/companion/config` API 同步到服务端。
