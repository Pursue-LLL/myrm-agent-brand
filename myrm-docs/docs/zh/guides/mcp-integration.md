# MCP 集成：让 Agent 接入任意外部工具

Model Context Protocol（MCP）是连接 AI Agent 与外部工具（数据库、CRM、工单系统、云平台以及数以千计的社区服务器）的行业标准协议。Myrm Agent 将 MCP 视为一等公民：一次配置，所有 Agent 即可调用你的工具，并具备企业级的可靠性与安全性。

## 为什么 Myrm 的 MCP 与众不同

| 能力 | Myrm Agent | 典型竞品 |
|---|---|---|
| **连接复用** | 持久 warm session——一次建连、终身复用，断线自动自愈重连 | 每次调用重新建连；延迟高、冷启动、频繁失败 |
| **协议代际** | MCP SDK 2.0 原生（无状态 HTTP、云负载均衡友好、协议自动协商、自研 `tool_converter`） | 多为 SDK 1.x，camelCase API 漂移 |
| **渐进披露** | 工具元数据 → 技能页 → 按需加载完整文档；token 高效 | 全量工具列表一次性灌入提示词 |
| **安全管道** | 7 层策略链（入口→挂载→分组→审批→子 Agent 拦截→MCP 过滤→方案确认）+ 运行时 prompt 注入扫描 | 极少或没有过滤 |
| **失败可见性** | 工具失败以结构化 `is_error` 信号呈现，模型可读取并重试 | 失败被静默当作"成功"文本 |
| **企业分发** | Org 级 MCP：IT 配置一次，全员 Agent 自动可用——配置类型自愈 + 云环境 stdio 自动过滤 | 静态配置文件经 OS 级工具下发，无实时同步 |

## 接入第一个 MCP 服务器

1. 打开 WebUI **设置 → MCP**。
2. 点击 **添加服务器**，选择传输方式：
   - **SSE / HTTP** —— 远程 URL（`https://...`），云端与团队共享推荐。
   - **Stdio** —— 本地命令（仅本地 / 桌面模式可用）。
3. 粘贴所需的请求头（例如 `Authorization: Bearer ...`）。
4. 保存。Myrm 自动发现工具、保持连接常驻，Agent 立即可调用。

> 已有配置缺少 `type` 字段？Myrm 会自动从 URL（`http(s)` → SSE/HTTP）或命令（→ stdio）推断类型，其他工具导出的旧配置无需手工修复即可迁移。

## 团队级 Org MCP

企业 / 云部署中，IT 管理员可在 **设置 → Enterprise → Org MCP**（仅 owner/admin）统一发布 MCP 服务器：

- 控制台配置一次，控制平面推送到每位成员的沙箱（休眠中的沙箱在唤醒时自动补推）。
- 员工在 MCP 设置页看到只读的 org 服务器列表，无法修改或删除。
- 云沙箱**默认拒绝本地 stdio 服务器**——多租户托管环境无本地进程攻击面。
- 可选绑定 **IdP 群组**（OIDC 自动同步）：财务拿到 ERP 连接器、研发拿到 CI/CD 连接器，离职即时撤销。

## 诊断与失败恢复

- 每次 MCP 调用双层超时 + 最多 3 次重试；传输错误触发 bounded backoff 自动重连，而不是工具报死。
- 工具级失败以结构化 `is_error` 返回，Agent 能看清失败原因并智能重试，而不是自信地汇报错误结果。
- 超大响应（>100K 字符）自动落入工件库（ArtifactVault）并返回摘要指针——不截断、不撑爆上下文。
- 服务器请求用户确认（MCP Elicitation）时，聊天内弹出 GUI 审批卡并带倒计时——不离开对话即可批准或拒绝。

## 安全说明

- 每次工具 freeze 前对 MCP 服务器做运行时 prompt 注入扫描，恶意描述被阻断（`MCPRuntimePostureError`）。
- 每个服务器支持工具 include/exclude 白名单、主机白名单、单服务器输出上限。
- OAuth 令牌过期触发热刷新与站内重新授权提示——绝不静默失败。
