# 画布工作区

Myrm 内置了基于 [tldraw](https://tldraw.dev) 的**无限画布**，为你提供一个自由的视觉工作空间，用于头脑风暴、绘制图表和视觉提示 —— 无需离开平台。

## 使用流程

<Steps>
  <Step title="创建画布">
    从侧边栏菜单导航到**画布**。点击**新建画布**创建一个全新的工作区。你可以管理多个画布 —— 随时重命名、切换或删除。
  </Step>
  <Step title="绘制和标注">
    完整的 tldraw 工具集可用：手绘、形状、文字、箭头、便签等。所有内容通过防抖自动保存 —— 无需手动保存。
  </Step>
  <Step title="Agent 交互">
    你的 AI Agent 可以读取画布状态、查看你选中的内容、并插入新元素。这实现了**视觉提示** —— 画一个草图，选中它，然后让 Agent 去完善或实现它。
  </Step>
  <Step title="实时同步">
    当 Agent 通过**内置服务端工具**（无需安装 MCP）修改画布时，变更会通过 SSE（服务端推送事件）即时显示。多个浏览器标签页保持同步。
  </Step>
</Steps>

## 启用画布工具

让 Agent 与你的画布交互：

1. 打开**聊天配置面板**（点击发送按钮旁的展开按钮）
2. 点击**内置工具**
3. 开启**无限画布**
4. 导航到或打开一个画布 —— Agent 会自动绑定当前活跃画布

启用后，Agent 获得四个画布操作能力：

| 工具 | 功能说明 |
|------|---------|
| **canvas_get_state** | 读取完整的 tldraw 快照 —— Agent 能看到画布上的所有内容 |
| **canvas_get_selection** | 读取你当前选中的图形 —— Agent 知道你的关注点 |
| **canvas_insert_element** | 向画布添加新图形（文字、便签、矩形、箭头等） |
| **canvas_batch_layout** | 一次性插入多个节点和连线，并自动排版（支持 Grid/Tree/Force 三种布局） |

### AI 自动排版（Canvas Auto-Layout）

`canvas_batch_layout` 是画布系统的核心能力 —— 让 Agent 一次 tool call 就能生成完整的知识图谱、架构图或思维导图：

- **Grid 布局**：适合平铺列表、卡片墙，节点从左到右排列，自动换行
- **Tree 布局**：适合层级关系、DAG 图，自动拓扑排序后分层展开
- **Force 布局**：适合关联网络、社交图谱，使用力导向算法让关联节点聚拢

插入完成后画布会自动缩放聚焦到新内容，带 400ms 过渡动画。

这使得以下工作流成为可能：
- 画一个线框图 → 让 Agent 根据它生成代码
- 选中一个图表 → 让 Agent 解释或改进它
- 让 Agent 可视化一个概念 → 它直接在你的画布上绘制
- 粘贴会议笔记 → 让 Agent 在画布上创建思维导图
- 说"把这些概念整理成关系图" → Agent 自动计算布局并一次性渲染

## 多画布管理

与单画布工具不同，Myrm 支持**多个独立画布**：

- 为不同的项目或头脑风暴会议创建画布
- 重命名画布以便识别
- 删除不再需要的画布
- 画布元数据存储在 SQLite 中；快照以 JSON 文件持久化

## 安全性

- **路径遍历防护**：画布 ID 在任何文件系统操作前都会验证为合法 UUID
- **非阻塞 I/O**：所有文件读写使用 `asyncio.to_thread`，避免阻塞事件循环
- **SSE 断线重连**：如果事件流断开，自动 3 秒退避重连

## 国际化

画布 UI 完整支持**英文**和**中文**本地化，包括所有标签、按钮、空状态和确认对话框。

## 为何选择 Myrm 而非 MCP 画布插件

| 如果你来自… | 常见痛点 | Myrm 的替代方案 |
|------------|----------|----------------|
| **Hermes + 自装 MCP** | 无内置画布；独立浏览器 tab；与聊天无绑定 | GUI 勾选**无限画布** — Agent 自动绑定当前活跃画布 |
| **OpenClaw / HTML 画布** | 仅为 HTML 快照，非 tldraw 协作板 | 完整 tldraw 编辑器 + 多画布 CRUD + SSE 同步 |
| **Cowart / Excalidraw MCP** | 需本地 Node；单画布；手动画布局 | Web 原生；**140 项自动化测试**；**AI 自动排版**（Grid/Tree/Force）一次调用 |
| **Obsidian 画布插件** | 节点随机堆叠，需手拖数分钟整理 | `canvas_batch_layout` + 400ms 自动 **zoomToFit** |

<Note>
画布**默认关闭** — 未启用时不占 LLM token。你仍可同时使用用户 MCP（GitHub、Notion 等）与内置画布。
</Note>
