# Agent 模板

从常见工作流的预配置模板起步。模板预设模型、工具、系统提示词、技能集与人格配置。

## 使用模板

1. 进入 **Agents > 新建 Agent**
2. 从画廊选择模板
3. 按需自定义（模型、工具、权限）
4. 保存并开始使用

## 模板市场

模板市场提供 9 个即用型模板，涵盖团队协作和垂直领域专家。点击任意模板即可一键创建已配好技能、提示词和头像的 Agent。

### 团队模板

| 模板 | 说明 |
|----------|-------------|
| **智能客服小队** | 分诊 + FAQ 专员 + 升级处理，覆盖客服全流程 |
| **深度研究分析小队** | 数据分析师 + 策略顾问 + 报告撰写，交付专业研究报告 |
| **软件开发小队** | 架构师 + 开发者 + 代码审查员，交付高质量代码方案 |
| **内容创作小队** | 写手 + 编辑 + 配图师，一站式完成内容创作 |

### 垂直领域专家模板

| 模板 | 绑定技能 | 说明 |
|----------|-------|-------------|
| **数据库诊断专家** | `db-diagnostics` | 系统化诊断数据库性能——连接、慢查询、索引、锁、膨胀，输出结构化报告 |
| **Office 文档助手** | `office-document` | 专业级 Excel 报表、PowerPoint 演示、Word 文档——公式驱动、格式规范 |
| **前端开发专家** | `frontend-development` | 生产级前端开发——组件设计、响应式布局、无障碍访问、性能优化 |
| **竞品动态追踪专员** | `competitive-analysis-pipeline` | 自动全网搜索竞品信息并生成标准周报 |
| **网页爬虫专家** | `web-scraping` | 结构化网页数据采集，自动处理分页、反爬、动态加载 |

### 内置预设

24 个内置智能体覆盖常见场景：通用助手、内容创作者、研究分析师、代码开发者、翻译器、SEO 策略师等。

## 创建自定义模板

将任意已配置 Agent 存为可复用模板：

1. 按所需设置配置 Agent
2. 进入 **Agent 设置 > 存为模板**
3. 填写名称、描述与分类
4. 模板出现在工作空间画廊

## 流水线模板

复杂多步工作流使用 **流水线模板**（由 PipelineWizard 驱动）：

- 在 Skill 文件 YAML frontmatter 中定义
- 含发现式问题、角色模板与任务图种子
- 从模板生成连接的看板任务 DAG

流水线详见[看板与编排](/zh/core-concepts/kanban-orchestration)。
