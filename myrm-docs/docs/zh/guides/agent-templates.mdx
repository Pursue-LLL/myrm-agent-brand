# Agent 模板

从常见工作流的预配置模板起步。模板预设模型、工具、系统提示词、技能集与人格配置。

## 使用模板

1. 进入 **Agents > 新建 Agent**
2. 从画廊选择模板
3. 按需自定义（模型、工具、权限）
4. 保存并开始使用

> 提示：第一次用？点智能体页的**分步指引**，四步走完模板、就绪检查与试用对话。

## 模板市场与输入框一键召唤

模板市场提供即用型模板，涵盖团队协作和垂直领域专家。您不仅可以在 **Agents > 模板市场** 浏览和安装，更可以直接在 **聊天输入框（MessageInput / FlowPad）** 实现原地发现与一键召唤：

- **智能推荐 Chip**：输入框上方根据精选团队与 Pareto 预设动态展示推荐 Chip，点击即可一键升级为专家会话并自动填充首条任务指令。
- **输入框工具栏「+」召唤浮层**：点击输入栏「+」快速呼出专家召唤浮层，支持即时检索、查看成员与 `use_cases` 场景，零页面跳转无缝完成召唤。
- **三阶段会商保障**：团队模板自动接入底层三阶段 Council 编排（独立分析 ➔ 交叉反驳 ➔ 首席仲裁），同沙箱零拷贝流转产物，有效消除单模型幻觉。

## 导出、导入与克隆

跨实例分享 Agent 配置或备份。

### 导出

从 **Agent 设置 > 导出** 将任意 Agent 导出为 JSON 文件。导出时自动剥离敏感认证字段（`api_key`、`auth_token`、`secret`、`password`、`token`），防止凭据泄露。团队 Agent 支持递归导出——所有 SubAgent 配置一并包含。

### 导入

通过 **Agent 设置 > 导入** 导入此前导出的 Agent JSON。导入的 Agent 始终创建为用户 Agent（`is_built_in=false`），防止恶意注入系统 Agent。

### 克隆

一键克隆可创建任意 Agent 配置的精确副本。副本获得新的 UUID 和名称后缀，保留所有设置（提示词、工具、技能、模型、人格）。

### 配置时光机

每次配置变更自动创建快照。进入 **Agent 设置 > 快照** 浏览最多 10 个历史版本，一键回滚——业界独有功能。

## 创建自定义模板

将任意已配置 Agent 存为可复用模板：

1. 按所需设置配置 Agent
2. 进入 **Agent 设置 > 存为模板**
3. 填写名称、描述与分类
4. 模板出现在工作空间画廊

## 流水线模板

复杂多步工作流使用 **流水线模板**（由 PipelineWizard 驱动）：

- 在 Skill 文件 YAML frontmatter 中定义

- 从模板生成连接的看板任务 DAG

流水线详见[看板与编排](/zh/core-concepts/kanban-orchestration)。
