# Agent 模板

从常见工作流的预配置模板起步。模板预设模型、工具、系统提示词、技能集与人格配置。

## 使用模板

1. 进入 **Agents > 新建 Agent**
2. 从画廊选择模板
3. 按需自定义（模型、工具、权限）
4. 保存并开始使用

## 模板市场

模板市场提供 9 个即用型模板，涵盖团队协作和垂直领域专家。点击任意模板即可一键创建已配好技能、提示词和头像的 Agent。

## Agent 集市（企业版）

对于团队和组织，**Agent 集市**让成员可以发布、发现和安装组织内的 Agent 配置——将个人专长沉淀为组织共享资产。

### 发布 Agent

发布 Agent 到组织集市时：

- **依赖打包** — Agent 引用的 Skill、MCP 工具和 SubAgent 自动打包进发布包
- **凭据剥离** — 7 类敏感字段（`api_key`、`auth_token`、`secret`、`password`、`token`、`credentials`、`private_key`）在发布前递归剥离
- **自动版本管理** — 每次发布自动递增版本号，历史版本可追溯

### 从集市安装

1. 从 **Agents > 集市** 浏览组织集市
2. 选择 Agent 点击 **安装**
3. Agent 配置自动推送到你的沙箱，UUID 自动重映射（无冲突）、依赖自动去重
4. 配置自己的 API Key 即可使用

### 集市功能

| 功能 | 说明 |
|------|------|
| **组织隔离** | 仅组织成员可浏览、发布和安装，外部用户无权访问 |
| **安装计数与热度排行** | 每次安装递增计数器，热门 Agent 优先展示 |
| **搜索与筛选** | 按名称或描述搜索，快速找到所需 Agent |
| **版本管理** | 获取最新版本或指定历史版本 |
| **归档管理** | 发布者可归档自己的条目，管理员可归档任意条目 |
| **RBAC 权限** | 发布需要组织成员身份，归档遵循发布者所有权和管理员特权 |
| **Force-Push 远程更新** | 管理员可将最新版本一键推送至所有已安装沙箱——ACTIVE 沙箱经控制平面 HTTP 导入即时生效，非 ACTIVE 沙箱跳过直至再次上线。推送前服务端自动快照当前配置，用户可一键回滚。推送按钮仅管理员可见 |
| **批量状态查询** | 列出集市条目时，单次优化查询显示所有条目的安装状态（无 N+1 性能问题） |

<Tip>
新员工可以在几分钟内通过安装集市中的成熟 Agent 配置快速上手，无需从零配置。
</Tip>

## 创建自定义模板

将任意已配置 Agent 存为可复用模板：

1. 按所需设置配置 Agent
2. 进入 **Agent 设置 > 存为模板**
3. 填写名称、描述与分类
4. 模板出现在工作空间画廊

## 流水线模板

复杂多步工作流使用 **流水线模板**（由 PipelineWizard 驱动）：

- 在 Skill 文件 YAML frontmatter 中定义
- 含发现式问题、角色模板与任务图种子
- 从模板生成连接的看板任务 DAG

流水线详见[看板与编排](/zh/core-concepts/kanban-orchestration)。
