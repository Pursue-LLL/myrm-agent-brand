# Agent 模板

从常见工作流的预配置模板起步。模板预设模型、工具、系统提示词、技能集与人格配置。

## 使用模板

1. 进入 **Agents > 新建 Agent**
2. 从画廊选择模板
3. 按需自定义（模型、工具、权限）
4. 保存并开始使用

## 模板分类

### 开发

| 模板 | 说明 |
|----------|-------------|
| **Code Assistant** | 全栈开发：文件编辑、终端、浏览器工具 |
| **Code Reviewer** | 只读分析：结构化反馈与安全扫描 |
| **DevOps Engineer** | Docker、CI/CD、基础设施管理 |

### 研究

| 模板 | 说明 |
|----------|-------------|
| **Research Analyst** | 网页搜索、文档分析、结构化报告 |
| **Data Analyst** | 代码执行、可视化、统计分析 |

### 效率

| 模板 | 说明 |
|----------|-------------|
| **Writing Assistant** | 内容创作与风格适配 |
| **Project Manager** | 任务拆解、进度跟踪、团队协调 |

## 创建自定义模板

将任意已配置 Agent 存为可复用模板：

1. 按所需设置配置 Agent
2. 进入 **Agent 设置 > 存为模板**
3. 填写名称、描述与分类
4. 模板出现在工作空间画廊

## 流水线模板

复杂多步工作流使用 **流水线模板**（由 PipelineWizard 驱动）：

- 在 Skill 文件 YAML frontmatter 中定义
- 含发现式问题、角色模板与任务图种子
- 从模板生成连接的看板任务 DAG

流水线详见[看板与编排](/zh/core-concepts/kanban-orchestration)。
