# 工作区文件预览

工作区文件浏览器展示 Agent 沙箱中的文件。点击任意文件，Myrm 自动决定展示方式——**文本按文本渲染，富媒体无需离开工作区即可预览**。

## 应用内预览类型

| 文件类型 | 行为 |
|----------|------|
| PDF | react-pdf 内联渲染，可滚动、可缩放 |
| 图片（PNG/JPEG/WebP/…） | 应用内全尺寸渲染 |
| 视频 / 音频 | 基于流式 URL 的应用内播放器 |
| SVG | 内联矢量渲染 |
| Markdown / 代码 / 纯文本 | 现有文本查看与编辑界面 |
| 未知或不支持的二进制 | 下载兜底——绝不出乱码 |

## 智能文本 / 二进制判定

Myrm 不靠猜测。后端在扫描时为每个文件条目标记权威 `is_text` 标志（零 I/O 扩展名检测），前端据此路由：

- **文本文件**带大小上限服务，超大日志不会卡死页面。
- **二进制文件**通过 HTTP Range 全量流式传输——完整 PDF，而不是截断片段，预览和下载都完整。

未知扩展名同样安全：后端无法判定为文本的文件一律按二进制处理、提供下载，而不是渲染成乱码。

## 安全下载

下载响应拦截响应头注入（剥离 CR/LF），非 ASCII 文件名按 RFC 5987 编码——中文、韩文或 emoji 文件名在任何平台都能正确下载。

## 预览内核

工件渲染器在聊天与工作区浏览器间复用：PDF、文档、表格、图片、视频、音频、SVG、交互 UI 预览共享同一渲染管线。工作区路径在此基础上叠加二进制流式与安全响应头。
