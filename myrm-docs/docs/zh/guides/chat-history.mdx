## 概览

MyrmAgent 提供了集成在侧边栏中的完整会话历史管理系统，无需跳转到单独页面。所有对话的搜索、整理和导出都可以在一个地方完成。

## 全文搜索 (Cmd+K)

在应用任意位置按 **⌘+K**（macOS）或 **Ctrl+K**（Windows/Linux）打开全局搜索对话框。

- **即时结果**：防抖搜索调用后端 `/chats/search` API
- **时间范围过滤**：可限定为今天、本周、本月或本季度
- **片段高亮**：搜索结果中匹配的文本自动高亮
- **点击跳转**：选中结果直接导航到对应会话，并高亮匹配的消息

## 日期分组

对话按时间自动分组：

| 分组 | 说明 |
|------|------|
| **今天** | 当天的会话 |
| **昨天** | 前一天的会话 |
| **近 7 天** | 一周内的会话 |
| **近 30 天** | 一个月内的会话 |
| **更早** | 30 天之前的会话 |

每个分组可以折叠/展开，折叠状态通过 `localStorage` 跨会话持久化。

## 置顶与拖拽排序

- **置顶对话**到侧边栏顶部，方便快速访问
- **拖拽排序**置顶项，使用 DnD-Kit SortableContext 实现
- 使用**数字快捷键**快速跳转到置顶会话

## 批量操作

进入批量模式可同时选择多个对话：

1. 从侧边栏标题切换批量模式
2. 逐一选择或使用「全选」
3. **批量导出**：选中对话后点击「导出」，选择格式（Markdown / JSON / HTML），所有对话将打包为 ZIP 下载
4. **批量删除**：删除的项目进入回收站（软删除，可恢复）

### 批量导出特性

| 特性 | 说明 |
|------|------|
| **3 并发处理** | 同时导出 3 个对话，大量对话时速度提升约 3 倍 |
| **失败自动重试** | 单个对话导出失败会自动重试一次，网络不稳定时不丢数据 |
| **按日期分文件夹** | ZIP 内按对话日期自动归类，如 `2026-07-15/对话标题.md` |
| **实时进度条** | 显示当前进度和正在处理的对话名称 |
| **可取消** | 导出过程中随时取消，不需要等待全部完成 |
| **容错跳过** | 个别对话失败不影响整体，完成后汇报成功/失败数量 |

## 导出对话

右键任意对话即可导出为四种格式：

- **Markdown** — 格式化的 `.md` 文件
- **HTML** — 可直接分享的样式化 HTML 页面
- **JSON** — 用于编程处理的结构化数据
- **复制到剪贴板** — 快速粘贴到任意位置

### 导出包含的诊断信息

导出文件自动包含以下元数据，便于调试和复现工作流：

| 信息 | 说明 |
|------|------|
| **Agent 身份** | 生成此回答的智能体名称、模型和描述 |
| **Tool Call 详情** | 每次工具调用的参数摘要、执行耗时和成功/失败状态 |
| **Token 用量** | 本次对话消耗的 Token 总量和费用估算 |
| **工具使用统计** | 各工具被调用的次数和总耗时 |

<Note>
工具参数中的敏感信息（API Key、密码、Token 等）会自动脱敏为 `***`，确保安全分享。
</Note>

### 打印对话

右键菜单中还提供「打印」选项，可将当前对话以专业排版打印或导出为 PDF。采用隐藏 iframe 方式调用浏览器原生打印，不会被弹窗拦截器阻断。

## 分享对话

通过右键菜单「分享」即可创建只读分享链接：

| 特性 | 说明 |
|------|------|
| **自签名安全** | HMAC-SHA256 签名 + TTL 自动过期（1-30 天可选） |
| **密码保护** | 可选设置访问密码，未授权无法查看 |
| **一键撤销** | 随时在侧边栏撤销已创建的分享链接 |
| **自托管** | 所有数据存储在你自己的服务器，不依赖第三方平台 |
| **安全头** | CSP + X-Frame-Options + X-Content-Type-Options 防范 XSS/点击劫持 |
| **限流保护** | 自动限流（30 次/分钟），防止恶意爬取 |

<Note>
分享链接为只读模式，接收方无法编辑对话内容。链接过期后自动失效。
</Note>

## 项目文件夹

将对话整理到带颜色标签的命名项目中：

- 通过右键菜单在项目间移动对话
- 筛选侧边栏仅显示特定项目的会话
- 项目归属跨会话持久化

## 回收站与恢复

不小心删除了对话？**会话回收站面板**提供：

- 软删除的对话保留用于恢复
- 一键还原已删除的会话
- 确认后可永久删除

## 来源过滤

按来源渠道过滤对话 — Web UI、Telegram、Discord、微信等 35+ 个平台。

## 无限滚动

侧边栏使用基于 `IntersectionObserver` 的无限滚动，没有翻页按钮。向下滚动时会话自动加载。

## 消息编辑与重新生成

编辑任何历史消息并重新发送，MyrmAgent 确保前后端完全一致：

1. **原子截断** — 编辑的消息之后的所有消息在发送前从数据库删除，Agent 永远不会看到过时的上下文
2. **版本保留** — 重新生成的回复存储为同级版本（`is_active` 标志）；使用消息旁的左右箭头切换版本
3. **智能重新生成** — 四种预设模式（重试 / 更简洁 / 更详细 / 更有创意）加自定义指令。指令以 `[Regeneration guidance: ...]` 注入 Agent 上下文，直接引导新回复
4. **Complaint-Up 自动升级** — 无自定义指令的纯重试被解读为隐式"不满意"信号，系统自动将模型 tier 提升一级（SIMPLE→STANDARD→REASONING），无需手动切换模型即可获得更高质量回复
5. **撤销最后一轮** — 一键删除最后一组用户+助手消息对

<Tip>
与只在前端截断的竞品不同，MyrmAgent 的后端优先方案防止"幽灵消息"污染 Agent 上下文 — 每次编辑都是全新的上下文。
</Tip>

## 流式中途纠偏（Busy Input）

当 Agent 正在生成回复时，按 Enter 发送消息将作为**纠偏重定向** — 立即中断当前生成，无需等待完成：

| 模式 | 行为 | 适用场景 |
|------|------|----------|
| **重定向**（默认） | 立即中断流式生成，保留已输出内容到上下文，用你的纠正消息开始新一轮 | Agent 方向错了 |
| **引导** | 等待当前生成/工具完成后，注入消息用于下一轮 | Agent 在做有用的事，但后续需要调整方向 |
| **排队** | 将消息加入队列，当前任务完成后自动发送 | 想排队安排后续工作而不打断当前任务 |

重定向模式的核心优势：
- **零浪费 Token** — 发现方向错误即刻停止（每次节省 200–1800 tokens）
- **上下文一致** — 已输出的部分 AI 回复作为 AIMessage 保留，LLM 看到的上下文与你看到的一致
- **提示词缓存友好** — 保留的部分文本维持消息前缀，提高下一次调用的缓存命中率
- **零学习成本** — 默认 Enter 行为，无需特殊快捷键

在**设置 → 智能体 → Busy Input 模式**中切换默认模式（重定向 / 引导 / 排队）。

## 与竞品对比

多数竞品（如 Hermes Agent）使用独立的 `/history` 页面，功能与侧边栏重复。MyrmAgent 遵循 ChatGPT、Claude 和 Gemini 的设计模式 — **侧边栏集成历史**，同时提供独立页面方案缺少的 16 项额外功能。

<Tip>
侧边栏模式让你的工作流不被打断。无需离开当前对话即可搜索、导出或管理历史记录。
</Tip>
