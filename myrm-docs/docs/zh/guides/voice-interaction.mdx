# 语音交互

在支持的渠道上使用语音与 Agent 交流。

## 支持的引擎

### 文字转语音（TTS）

5 种 TTS 引擎，用于 Agent 语音输出。

### 语音转文字（STT）

5 种 STT 引擎：本地 Whisper（免费、隐私优先）、OpenAI Whisper、Groq、Deepgram 和 xAI Grok STT。支持通过 Base URL 设置接入任意 OpenAI 兼容 STT 端点。

### 视频音频转录

视频消息（包括 Telegram 圆形视频消息）会自动通过 STT 管道转录。Agent 无需额外配置即可理解视频中的语音内容。

## 设置

1. 进入 **设置 > 语音**
2. 选择偏好的 TTS 与 STT 引擎
3. 配置语言与音色偏好
4. 如需自定义 STT 端点，设置 Base URL 字段（OpenAI 和 xAI 提供商可用）

## 安全

所有语音数据端到端加密（E2EE）处理。除非显式配置，否则不存储音频。
