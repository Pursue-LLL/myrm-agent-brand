# 批量目录运行

用**一条指令**在**多个工作目录**上并行执行同一个任务。适合用一条 prompt 审计多个仓库的安全问题、在多个项目上批量执行迁移、或为每一个代码库生成统一的状态报告。

## 创建批量运行

打开侧边栏 **批量目录**，点击 **新建运行**，配置：

| 配置项 | 作用 |
|--------|------|
| **名称** | 批次项目标识 |
| **指令** | 应用到每个目录的同一条指令 |
| **目录** | 待处理的工作区（每个目录对应一条 Agent 任务） |
| **并发数** | 同时处理的目录数量 |
| **智能体与模型** | 可选绑定智能体 / 按批次覆盖模型 |
| **最大运行时长** | 每个目录的超时保护（秒） |
| **需要审批** | 每个结果都要人工通过/驳回后才生效 |
| **产物匹配模式** | Agent 必须产出的文件 glob（如 `**/security-report.md`） |
| **通知** | 完成时站内 + IM 渠道提醒 |

危险路径（用户主目录、`/etc`、文件系统根、`~`、`..` 穿越）在创建时即被拒绝，重复目录会自动去重。

## 监控进度

详情页实时展示状态、每个目录的标签页与聚合计数。**失败**或**未产出所需产物**的目录会被高亮标出，一眼定位问题。运行结束后展示总耗时。

## 失败处理

不必整批重跑，精准恢复：

- **重试失败目录** —— 只为失败或缺失产物的目录重新下发任务
- **重试单个目录** —— 只重跑一条任务
- **全部重跑** —— 重新入队所有目录（仅限终态项目，避免重复）

重试按目录代次追踪，某目录重试成功后整个项目可回到 **已完成** —— 即使之前的尝试失败过。

## 暂停与审批

- **暂停**会中断正在执行的 Agent 并冻结队列；**恢复**从暂停处精确继续。
- 开启 **需要审批** 后，每一条验证通过的任务都会进入 *待审核*，等待你通过/驳回。**全部通过** 一键完成整批收尾。

## 通知

批次达到终态时，你会收到站内通知，同时（若绑定智能体配置了通知目标）收到 IM 渠道消息——汇总结果统计、耗时与失败目录列表。消息内含直达项目详情页的深链，从聊天即可跳转查看完整运行。

## 典型场景

- 用一条指令审计 N 个仓库的安全/许可问题
- 在多个项目上批量应用同一重构/迁移
- 为名下每个目录生成统一的状态报告
