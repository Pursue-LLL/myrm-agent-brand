# 隧道

通过内置隧道，从任意位置访问本地托管的 Myrm 实例。

## 原理

Myrm 集成 Cloudflare Tunnel，通过安全加密隧道暴露本地实例。

## 设置

1. 打开 **设置 > 系统**
2. 启用**密码保护**（Tauri 必填；浏览器本地模式默认开启）
3. 在 **Quick Tunnel** 下点击 **启动隧道**
4. 复制生成的公网 URL（Webhook 自动同步到 **公网入口**）

## 使用场景

- 用手机访问家中 Agent
- 临时与团队成员共享 Agent
- 将消息渠道连接到本地实例

## 稳定自定义域名

Quick Tunnel 使用随机 `trycloudflare.com` 主机名。生产 **固定域名**（Webhook）：

1. 创建 [Cloudflare Named Tunnel](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/)（或其他反向代理）指向 WebUI 端口（默认 `3000`）。
2. 在 **设置 > 系统** 将 **公网入口** 设为 `https://your.domain`（勿启动 Quick Tunnel）。
3. 运行 **连通性测试**，再配置消息渠道。

## 安全

- 全程端到端加密
- 启动 Quick Tunnel 前启用**密码保护**
- Quick Tunnel URL 每会话变化；长期 Webhook 请用稳定域名

## 故障排除

### `cloudflared binary not found`

- **Tauri 桌面端**：应用捆绑 `cloudflared`；若 sidecar 缺失请重装或更新桌面版。
- **WebUI / 开发**：安装 [cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/) 并确保在 `PATH`，或启动服务前设置 `CLOUDFLARED_PATH` 为完整二进制路径。

### 隧道启动超时或立即失败

1. 确认 **设置 > 系统** 中的 WebUI 端口与 Myrm 实际监听端口一致（默认 `3000`）。
2. 查看服务端日志 `Quick Tunnel failed` — 含 **cloudflared stderr** 末行以显示真实错误（防火墙、DNS 或 Cloudflare 故障）。
3. 一分钟后重试；未绑定 Cloudflare 账号时 Quick Tunnel 为尽力而为。

### 渠道页 Webhook 仍显示 `localhost`

1. 先在 **设置 > 系统** 启动 **Quick Tunnel**（或设置 **公网入口**）。
2. 重新打开渠道页，使 Webhook URL 从公网入口解析器刷新。
3. 生产 Webhook 请用**稳定自定义域名**，勿用随机 `trycloudflare.com` URL。
