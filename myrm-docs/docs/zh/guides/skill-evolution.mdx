# 技能自进化

Myrm 的技能进化引擎**自动将成功的交互转化为可复用技能**。不同于简单的 prompt 存储，引擎运行完整管线：轨迹分析 → 结构化提取 → 自动筛选 → 沙箱验证 → LLM 评审 → GUI 人工审批。

## 工作原理

1. **轨迹分析** — 每次对话后，`TraceAnalyzer` 以 5 层渐进式披露提取执行轨迹，识别值得固化为技能的模式。
2. **结构化提取** — `StructuredExtractor` 利用 LLM 捕获技能定义并附带置信度评分，确保只有高质量模式被提升。
3. **自动筛选** — 低质量或重复的提取在到达你之前就被过滤。
4. **沙箱验证** — 候选技能在安全沙箱环境中执行，验证其确实可用。
5. **LLM 评审** — 自动评审器检查边界情况、安全问题和正确性。
6. **人工审批** — 未经你同意，任何技能都不会上线。在**待审进化面板**中审核。

## 审核待定技能

1. 进入 **设置 → 技能 → 待审进化**。
2. 以**列表**或**网格**视图浏览提案。
3. 对每个提案：
   - **批准** — 立即部署技能。
   - **拒绝** — 丢弃提案。
   - **修订** — 在 Monaco diff 编辑器中编辑后再批准。
4. 批准的技能将在未来对话中供 Agent 使用。

## 变体测试

当 Myrm 检测到技能可改进时，会生成变体并进行 A/B 对比。你可以在 **Shadow GUI** 面板中查看变体结果，确认后再推广到生产。

## 版本历史与回滚

每次技能变更都有记录：

- **历史面板** — 完整进化时间线及 diff。
- **版本面板** — 任意两个版本并排对比。
- **一键回滚** — 瞬间恢复到任何历史版本。

## 批量优化

对于大型技能库：

1. 进入 **设置 → 技能 → 批量优化**。
2. 点击**运行优化** — 引擎评估所有技能的改进机会。
3. 审核批次快照，逐一批准/拒绝。
4. 支持批次中途回滚。

## 后台复盘

Myrm 在空闲时段运行 4 种后台异步任务：

- 从成功对话中静默提取技能
- 压缩冗长技能以降低 Token 消耗
- 挫败感检测 → 自动生成修复变体
- 清理低价值技能

所有后台变更仍需你批准后才会部署。
