# 认证

## API Token

在 GUI **设置 > API Keys** 中生成 API Token。

## 用法

在 `Authorization` 头中携带 Token：

```bash
Authorization: Bearer myrm_sk_...
```

## Token 作用域

| 作用域 | 说明 |
|-------|-------------|
| `agent:read` | 读取 Agent 配置 |
| `agent:write` | 创建与修改 Agent |
| `memory:read` | 读取记忆条目 |
| `memory:write` | 创建与修改记忆 |
| `tool:execute` | 执行工具 |

## Token 轮换

可在 API Keys 设置页随时轮换 Token，旧 Token 立即失效。
