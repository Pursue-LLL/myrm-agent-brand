# Work Units 与成本管理

Myrm 提供覆盖所有部署模式的完整成本管理体系 —— 从 SaaS Work Unit 计费、本地 BYOK 预算控制，到全链路分析仪表盘。

## Work Units（SaaS）

Work Units 是 SaaS 平台所有用量的统一计量单位。

### 消耗 WU 的活动

| 活动 | 费率 |
|----------|------|
| LLM 输入 Token | 因模型而异 |
| LLM 输出 Token | 因模型而异 |
| 工具执行 | 按次 |
| 沙箱活跃时长 | 按分钟 |
| 文件存储 | 按 GB/月 |

### 套餐

| 套餐 | WU/月 | 价格 | 附加 |
|------|----------|-------|--------|
| Free | 600 | $0 | 每日刷新 +50 |
| Companion | 6,000 | $19/月 | 无限 Agent |
| Pro | 18,000 | $49/月 | 7 天免费试用 |
| Max | 60,000 | $149/月 | 专属支持 |

## Token 效率

Myrm 优化后的系统提示词仅约 1,765 tokens，同类平台常达 15,000+。配合 Prompt 缓存，有效成本最高可降低 97%。

## 本地 / 桌面端

本地 WebUI 与 Tauri 桌面模式不消耗 WU。你通过 BYOK（自带 Key）直接向 LLM 提供商付费。

## 预算控制

Myrm 内置三维预算系统，全方位保护你免受意外成本。

### 三个维度

| 维度 | 限制范围 | 示例 |
|------|---------|------|
| 每会话 | 单次对话成本上限（按 `session_id` 多标签页物理隔离，并发无干扰） | 每次聊天 $2.00 |
| 每日 | 当天总消费上限（统一按 UTC 零点精准重置并支持重启恢复） | 所有聊天合计 $10.00/天 |
| 每次调用 | 单次 LLM 调用成本上限 | 每次 API 调用 $0.50 |

### 四级渐进响应

1. **OK** — 正常运行
2. **WARNING** — 接近上限（默认 80%），弹出 Toast 提醒并无损提示注入
3. **FINALIZATION** — 预留 15% 缓冲储备金放行，引导 Agent 归纳交付已完成成果，杜绝半成品代码
4. **EXCEEDED** — 硬性熔断停止，新消息被阻断直到手动调整或重置

在 **设置 > 系统 > 预算策略** 中配置。预算执行机制采用尾部 prompt injection 方式，保证 Prompt 缓存前缀稳定性（KV Cache 命中率 99%+）不被破坏。同时支持前端多 Tab 会话账本隔离，切换标签页或并发执行互不踩踏清零。

## 企业组织预算（仅云端）

云端部署的企业组织管理员可以设定团队级月度 WU 预算并配置自动告警阈值。

### 工作原理

1. 管理员设定月度 WU 预算和告警阈值（例如 10,000 WU，80% 触发告警）
2. 系统实时追踪所有团队成员的 WU 消耗
3. 当组织总用量超过阈值时自动发送告警
4. 告警每月幂等 —— 不会产生告警风暴
5. 修改阈值会重置告警标记，新阈值立即生效

### 用量摘要 API

`/api/enterprise/org/{org_id}/usage-summary` 端点返回详细分解：

- **成员维度** — 每个团队成员本月的消耗量
- **分类维度** — LLM 输出、工具执行等
- **用量比率** — 当前消耗 vs 月度预算
- **预算状态** — 是否已触发阈值

此功能仅适用于控制平面的云端企业部署。

## 成本分析仪表盘

进入 **设置 > 系统 > 用量统计** 查看完整的成本分析面板。

### 仪表盘内容

- **全局概览** — 总调用次数、Token 用量（7 种类型）、总成本、缓存命中率
- **日趋势** — 7 天或 30 天 Token 用量与成本时间序列
- **模型分解** — 每个使用的模型的调用次数、Token 数和成本
- **路由分析** — 智能路由如何分配任务到不同层级（简单/标准/推理）
- **路由节省估算** — 如果不用智能路由你需要花多少 vs 实际花了多少
- **缓存节省** — 缓存省下的金额 + 缓存中断诊断
- **活动热力图** — 一周中你的活跃时段分布
- **Top 会话排行** — 成本最高的对话排名
- **会话钻取** — 点击任意会话查看详细的 Token/工具/时间线分析

### 每消息实时成本

每条 AI 回复旁都会显示一个 **水滴图标**，实时展示该条回复的具体成本，包括缓存节省百分比。在 **设置 > 个人 > 显示成本估算** 中启用。

### 上下文使用环

消息输入框旁的圆环指示器实时显示当前模型上下文窗口的使用率，随使用率升高变色：
- **绿色** — 健康（<75%）
- **琥珀** — 接近上限（75-90%）
- **红色** — 临界（>90%）
