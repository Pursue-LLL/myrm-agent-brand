# 竞品对比与迁移指南

MyrmAgent 定位为完整的 AI Agent 原生工作空间。与仅支持终端命令行的代码助手不同，MyrmAgent 提供持久化沙箱、跨会话记忆与企业级安全，同时具备全栈工程开发能力。

<Note>
**迁移信心保障** — 支持 SaaS 云端、本地自托管或桌面端；支持一键通过 WebUI 导入 Hermes 技能包。MyrmAgent 支持一键安装完整 Agent 包（模型 + 技能 + MCP + 子智能体 + 安全策略）。文档支持 6 种语言（zh/en/ja/ko/de/zh-TW），跨 WebUI、云端托管与 Tauri 桌面端自动感知语言。
</Note>

## 最新验证快照（2026-08-28 · 零噪音多语言 SSOT 与 5 大结构化定时自动化工具链 · 工具生态完成）

- **CronManageToolBilingualSSOTAndFivePatternStructuredAutomation（对比 Hermes 仅 CLI crontab / OpenClaw 简单调度 / HappyCapy Turn1 静态模板臃肿与 Prompt Cache 失效）：** MyrmAgent 交付针对 `cron_manage_tool` 的企业级 LLM 可见工具描述 SSOT 与 5 大结构化自动化架构：
  1. **零噪音中英双语 SSOT 物理隔离（`_cron_tool_description.py`）**：彻底将 LLM 可见提示词定义与调度引擎物理依赖解耦（`CRON_MANAGE_TOOL_DESCRIPTION_EN` 与 `_ZH`），剔除开发者实现细节（LiteLLM/SQLite/IP 拓扑），实现亚微秒级按需多语言解析；
  2. **5 大核心调用模式结构化提示词工程**：清晰引导模型使用 5 种标准自动化模式（Agent 自然语言任务、沙箱 Shell 任务、免 LLM 纯提醒、按需蓝图自动化、实时流/轮询事件触发），彻底消除参数幻觉与互斥冲突；
  3. **按需渐进式披露守护 Turn1 Prompt Cache 100% 命中**：蓝图模板通过 `action='blueprints'` 按需动态拉取，避免在 Turn1 系统提示词中全量注入模板目录，保障 100% KV Cache 命中率；
  4. **多渠道与会话语言自动感知注入（`tool_setup.py`）**：无缝将 `tool_description_locale` 与用户当前会话或 IM 渠道语言强绑定；
  5. **100% 全栈测试覆盖与零技术债**：通过 116 项 `test_cron_manage_tool.py` 单元测试、87 项 Server Cron 生命周期 API 测试以及 676 项 Harness Cron 回归测试套件（884 项测试全部通过，100% 绿灯，0 Lint 错误，0 僵尸进程）。
