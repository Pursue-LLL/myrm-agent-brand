# 桌面应用（Tauri）

Tauri 桌面客户端在本地运行后端与原生 UI，所有数据留在你的机器上。

## 下载与安装

Myrm Desktop 具备智能跨平台分发能力：

1. **智能硬件匹配**：下载页使用 WebGL 探测绕过浏览器限制（如 Safari 在 M 系列芯片上伪装 Intel），确保一键获取针对你设备的最优二进制（Apple Silicon vs Intel）。
2. **无竞态自动更新**：Map-Reduce CI/CD 流水线保证各平台可靠、静默的后台更新，无 manifest 冲突。

从 [Myrm 官网](https://myrmagent.ai) 或 [GitHub Releases](https://github.com/Pursue-LLL/myrm-agent/releases) 获取最新版本。

## 设置

1. 为你的平台安装应用
2. 从应用程序菜单启动 Myrm
3. 在设置中配置至少一个 LLM API Key

## 远程访问

通过内置隧道支持远程访问：

1. 进入 **设置 > 系统**
2. 启用 **WebUI 模式**与**密码保护**
3. 启动**公网访问（隧道）**，从任意设备使用生成的 URL

详细配置见[隧道指南](/zh/guides/tunnel)。
