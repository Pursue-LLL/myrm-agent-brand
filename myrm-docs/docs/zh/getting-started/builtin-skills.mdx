# 内置技能与出厂默认集

全新安装 Myrm 后，你**无需任何配置**即可直接发起这几类高频办公任务：读文档、数据分析、联网调研、生成 Word/PPT/Excel、导出 PDF。

## 出厂默认启用的 5 个技能

| 技能 | 典型用途 |
|------|----------|
| **数据分析**（`data-analysis`） | 清洗与分析表格数据、产出结论与图表 |
| **深度调研**（`deep-research`） | 多轮检索、交叉验证、带来源的研究报告 |
| **文档解析**（`document-extraction`） | 从 PDF / HTML / Markdown 抽取结构化内容与表格 |
| **办公文档生成**（`office-document`） | 生成与编辑 **Excel (.xlsx)、PowerPoint (.pptx)、Word (.docx)** |
| **PDF 生成**（`pdf-generator`） | 发票、审计报告、分析报告等高保真 PDF（含中文渲染） |

<Note>
**为什么是这五个，而不是全部 144 个？**
出厂集刻意保持**小而准**：只放跨行业通用的本地处理型工作流，既避免首轮把大量技能说明塞进上下文造成浪费与误触发，也让你在第一次对话就有可用产出。其余技能随时可自行开启。
</Note>

## 三个你需要知道的行为

<Steps>
  <Step title="只对全新安装生效">
    默认集**仅在系统首次创建技能配置时写入**。已经使用过的账户，其启用/停用选择**永远不会被默认值改写**——升级、加新技能都不会动你的既有配置。
  </Step>
  <Step title="默认集与实际技能强绑定">
    默认清单只会保留**当前确实存在**的技能。若某个技能在后续版本被移除或改名，它会自动从默认集中剔除，不会留下失效项。
  </Step>
  <Step title="随时可关，不会自己回来">
    在 **设置 → 技能** 中关闭任意默认技能后，它会被记入你的停用列表，**后续重启或升级都不会被重新打开**。
  </Step>
</Steps>

## 如何增删启用

1. 打开 **设置 → 技能**（侧边栏「技能」入口亦可）。
2. 顶部「已装备」标签会显示当前启用数量；在预置技能列表中勾选或取消勾选即可。
3. 启用后**下一条消息**生效——技能会以「名称 — 说明」的形式进入可用目录，模型在任务匹配时按需加载详细流程。

<Note>
**为什么关掉后不会自己回来？**
停用操作会写入你的个人配置并被优先于任何默认策略。界面显示的启用状态与后台真实状态始终一致，不存在「界面关了、后台还在跑」的情况。
</Note>

## 与竞品的差异

- **OpenClaw / Hermes**：默认把技能**全开**——能力多，但首轮上下文开销大，弱模型更容易误触发工具。
- **OpenCode / Pi**：架构同样清爽（目录进消息、正文按需加载），但**办公文档产出需要自行接入外部工具**。
- **Myrm**：**既不空手、也不塞满**——出厂即有 5 个精选通用办公技能，含 Word/PPT/Excel 生成，且**全部可见、可一键关闭**。

更多横向对比见 [竞品对比与迁移指南](/getting-started/competitor-comparison)。
