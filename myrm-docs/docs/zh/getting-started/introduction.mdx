# 欢迎使用 Myrm

Myrm 是一个**开放核心（open-core）** AI Agent 工作空间：WebUI、API 服务端与 Tauri 桌面端为开源；Agent Harness 运行时与 SaaS 控制平面为专有组件。你获得持久化 per-user 沙箱、跨会话记忆，以及 GUI 优先的体验，支持 100+ LLM 模型、24+ 消息渠道，以及三种部署模式——本地 WebUI、Tauri 桌面端或 SaaS 云端。

## 核心能力

| 能力 | 说明 |
|------------|-------------|
| **目标管理** | 定义目标，4D 预算控制、验收标准与自主执行 |
| **看板** | 可视化任务管理，DAG 依赖、优先级调度与僵尸任务检测 |
| **子 Agent 编排** | 6 种模式（Spawn / Chain / Batch / DAG / Verified / Swarm），零信任校验、UI 黑名单、智能预算降级与无缝 HITL 上下文注入 |
| **上下文工程** | 5 层压缩流水线，可逆归档，97% Prompt 缓存命中率 |
| **24+ 渠道** | 微信、Telegram、Discord、Slack、邮件、短信——从任意平台与 Agent 交互 |
| **6 层安全** | 纵深防御：预算控制、权限、循环检测、PII 保护与审计追踪 |
| **Computer Use** | 通过原生屏幕控制实现桌面自动化（macOS + Linux） |
| **Web 搜索 + 抓取** | 7 个搜索引擎，BM25/Reranker 过滤 + 3 级本地抓取与 DOM 剪枝——$0/月 |
| **语音交互** | 5 种 TTS + 4 种 STT 引擎，端到端加密 |
| **产物部署与分享** | 从预览 Vercel 部署，或 7 天只读分享链接（html/pdf/docs）——多文件静态包、部署预检、无需 Git |

## 部署选项

| 模式 | 说明 | 成本 |
|------|-------------|------|
| **本地 WebUI** | 基于浏览器，自托管于本机 | 免费（BYOK） |
| **Tauri 桌面端** | 原生桌面应用，内嵌后端 | 免费（BYOK） |
| **SaaS 云端** | 托管基础设施，Work Units 计费 | 免费档 + 付费计划 |

三种模式共享同一套代码与功能集。数据与配置可在模式间迁移。

## Token 效率

Myrm 优化后的系统提示词仅约 **1,765 tokens**——比同类平台少 **86%**。配合 Prompt 缓存，有效成本最高可降低 **97%**。

## 开源与 Harness

**WebUI 与 API 服务端**为开源。**Agent Harness**（工具、记忆引擎、浏览器池）作为生产运行时打包在你的沙箱内。完整架构见[产品架构](/zh/getting-started/product-architecture)。
