# 欢迎使用 Myrm

Myrm 是一个**开源** AI Agent 工作空间：WebUI、API 服务端、Tauri 桌面端与 Agent Harness 运行时均为 MIT 开源；仅可选的 SaaS 控制平面为专有组件。你获得持久化 per-user 沙箱、跨会话记忆，以及 GUI 优先的体验，支持 100+ LLM 模型、26 消息渠道，以及三种部署模式——本地 WebUI、Tauri 桌面端或 SaaS 云端。

## 核心能力

| 能力 | 说明 |
|------------|-------------|
| **目标管理** | 定义目标，4D 预算控制、验收标准与自主执行 |
| **看板** | 可视化任务管理，DAG 依赖、优先级调度与僵尸任务检测 |
| **子 Agent 编排** | 6 种模式（Spawn / Chain / Batch / DAG / Verified / Swarm），零信任校验、UI 黑名单、智能预算降级与无缝 HITL 上下文注入 |
| **上下文工程** | 5 层压缩流水线，可逆归档，Prompt 缓存 |
| **26 渠道** | 微信、Telegram、Discord、Slack、邮件、短信——从任意平台与 Agent 交互 |
| **6 层安全** | 纵深防御：预算控制、权限、循环检测、PII 保护与审计追踪 |
| **Computer Use** | 通过原生屏幕控制实现桌面自动化（macOS + Linux） |
| **Web 搜索 + 抓取** | 7 个搜索引擎，多查询合并去重 + 3 级本地抓取与 DOM 剪枝——$0/月 |
| **语音交互** | 7 种 TTS + 5 种 STT 引擎，含免费本地方案 |
| **产物部署与分享** | 16+ 可预览格式，含交互式电子表格查看器（CSV/XLSX 支持排序、搜索、导出），Vercel 一键部署，1–30 天可撤销只读分享链接（可选密码门，一键撤销即时 404）——多文件静态包、部署预检、无需 Git |

## 部署选项

| 模式 | 说明 | 成本 |
|------|-------------|------|
| **本地 WebUI** | 基于浏览器，自托管于本机 | 免费（BYOK） |
| **Tauri 桌面端** | 原生桌面应用，内嵌后端 | 免费（BYOK） |
| **SaaS 云端** | 托管基础设施，Work Units 计费 | 免费档 + 付费计划 |

三种模式共享同一套代码与功能集。数据与配置可在模式间迁移。

## Token 效率

在基准配置下，Myrm 首轮工具披露约 **1,765 tokens**（启用更完整工具集时约 2,167），明显低于一次性平铺所有工具的做法。配合 Prompt 缓存，有效成本还可以进一步下降。请把这些数字理解为特定工具集下的实测默认值，而不是普适保证：你启用的工具、技能和模型都会改变结果。

## 哪些部分开源

**WebUI、API 服务端、Agent Harness 与 Tauri 桌面壳均为 MIT 开源**。可选的 SaaS 控制平面（多租户计费、LLM 中继、舰队管理）为专有组件；你不是必须用它才能自己运行产品。

这个分层是刻意设计的：接触你的文件、记忆、技能与模型 Key 的部分，可以被审计、fork 和自托管。逐层契约见[产品架构](/zh/getting-started/product-architecture)。
