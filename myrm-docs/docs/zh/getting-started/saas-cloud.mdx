# SaaS 云端

托管 SaaS 方案提供隔离的 per-user 沙箱，零 DevOps 负担。

## 上手

1. 访问 [app.myrmagent.ai](https://app.myrmagent.ai/auth/login)
2. 使用邮箱或 OAuth 创建账号
3. 工作空间立即可用

## Work Units

所有 SaaS 用量通过统一的 **Work Units（WU）** 余额计费：

| 计划 | WU/月 | 价格 |
|------|----------|-------|
| Free | 600 + 每日刷新 50 | $0 |
| Companion | 6,000 | $19/月 |
| Pro | 18,000 | $49/月 |
| Max | 60,000 | $149/月 |

WU 消耗细则见 [Work Units](/zh/core-concepts/work-units)。

## 数据与隐私

- 每位用户获得隔离的持久化沙箱卷
- API Key 存储在加密密钥库中（AES-256-GCM 加密 + 密钥轮换）
- 完整说明见[隐私政策](https://myrmagent.ai/privacy)

## 企业级基础设施

托管 SaaS 平台基于 21 层企业级基础设施构建：

| 层级 | 能力 |
|------|------|
| 隔离 | Per-User 独立沙箱 + 专属 Volume（非共享进程多租户） |
| 配额 | 三层资源配额（per-user / per-sandbox / per-task） |
| 限流 | 可配置的 per-resource、per-user 速率限制 |
| 网络 | 出口控制 + 命令白名单 |
| 密钥 | AES-256-GCM 加密保管库 + 密钥轮换 |
| 认证 | OAuth/OIDC + 企业 JWT 许可证验证 |
| 监控 | 舰队健康监控 + 失败阈值告警 |
| 可观测 | Prometheus 导出 + 多租户指标聚合 |
| 恢复 | 状态和解器（DB/容器/WS 三方一致性校验） |
| 伸缩 | 资源伸缩器（空闲 CPU 降频）+ 沙箱回收器 |
| 审计 | 完整审计日志（查询/统计/CSV/JSON 导出） |
| 安全 | 紧急停止开关（Killswitch） |

全部 811 项基础设施测试通过，零失败。
