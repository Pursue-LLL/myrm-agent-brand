# SaaS 云端

托管 SaaS 方案提供隔离的 per-user 沙箱，零 DevOps 负担。

## 上手

1. 访问 [app.myrmagent.ai](https://app.myrmagent.ai/auth/login)
2. 使用邮箱、Google OAuth 或 GitHub OAuth 创建账号
3. 工作空间立即可用

## 套餐

所有 SaaS 用量通过统一的 **Work Units（WU）** 余额计费。每个付费套餐都包含一个专属沙箱，配置如下：

| 套餐 | 价格 | WU/月 | 沙箱 | 存储 | 附加 |
|------|------|-------|------|------|------|
| Free | $0 | 600 + 每日刷新 50 | 共享 | 5 GB | — |
| Companion | $17/月 | 6,000 | 1 vCPU / 2 GB RAM | 20 GB | 无限 Agent |
| Plus | $42/月 | 5,000 | 2 vCPU / 4 GB RAM | 50 GB | 优先队列 |
| Pro | $79/月 | 12,000 | 4 vCPU / 8 GB RAM | 100 GB | 7 天免费试用 |
| Max | $167/月 | 60,000 | 8 vCPU / 16 GB RAM | 200 GB | VNC 桌面、专属支持 |

<Note>
Pro 套餐包含 **7 天免费试用**，试用期内可随时取消，不收取任何费用。
</Note>

WU 消耗细则见 [Work Units](/zh/core-concepts/work-units)。

## 沙箱规格

每个付费套餐都会预置一个持久化、隔离的 Linux 沙箱，规格按层级递增：

- **Companion** — 轻量脚本、单 Agent 任务
- **Plus** — 2 核沙箱上的多步 Agent 工作流
- **Pro** — 4 核沙箱上的高并发 Agent 任务
- **Max** — 8 核沙箱 + 200 GB 存储，内置 **VNC 桌面**，可用于浏览器自动化、GUI 工具和远程桌面访问

## 计费与支付

- **Creem** 是 Myrm 云端订阅的商户记录（Merchant of Record），代为处理支付、发票与税务。
- 订阅按月续费，可在 **设置 > 计费** 中随时取消。
- 每次成功扣款后，Creem 会向你邮箱发送发票与收据。

## 数据与隐私

- 每位用户获得隔离的持久化沙箱卷
- API Key 存储在加密密钥库中（AES-256-GCM 加密 + 密钥轮换）
- 完整说明见[隐私政策](https://myrmagent.ai/privacy)

## 企业级基础设施

托管 SaaS 平台基于 21 层企业级基础设施构建：

| 层级 | 能力 |
|------|------|
| 隔离 | Per-User 独立沙箱 + 专属 Volume（非共享进程多租户） |
| 配额 | 三层资源配额（per-user / per-sandbox / per-task） |
| 限流 | 可配置的 per-resource、per-user 速率限制 |
| 网络 | 出口控制 + 命令白名单 |
| 密钥 | AES-256-GCM 加密保管库 + 密钥轮换 |
| 认证 | OAuth/OIDC + 企业 JWT 许可证验证 |
| 监控 | 舰队健康监控 + 失败阈值告警 |
| 可观测 | Prometheus 导出 + 多租户指标聚合 |
| 恢复 | 状态和解器（DB/容器/WS 三方一致性校验） |
| 伸缩 | 资源伸缩器（空闲 CPU 降频）+ 沙箱回收器（双信号空闲检测：代理活跃同步 + WS 连接防护） |
| 审计 | 完整审计日志（24 类事件）+ 可视化大盘（KPI 卡片、时序图、事件分布）+ CSV/JSON 导出 |
| 成本管控 | 组织用量汇总（成员排行 + 分类统计）+ 可配置月度预算与阈值告警 |
| Org MCP | 企业 IT 在 Enterprise 设置中 CRUD/编辑；HTTP 推送到成员沙箱；休眠唤醒后自动补推；云环境禁止 stdio MCP；员工只读查看组织托管列表 |
| 安全 | 紧急停止开关（Killswitch） |

全部 940+ 项基础设施测试通过，零失败。
