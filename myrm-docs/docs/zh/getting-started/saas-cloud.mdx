# SaaS 云端

托管 SaaS 方案提供隔离的 per-user 沙箱，零 DevOps 负担。

## 上手

1. 访问 [app.myrmagent.ai](https://app.myrmagent.ai/auth/login)
2. 使用邮箱或 OAuth 创建账号
3. 工作空间立即可用

## Work Units

所有 SaaS 用量通过统一的 **Work Units（WU）** 余额计费：

| 计划 | WU/月 | 价格 |
|------|----------|-------|
| Free | 600 + 每日刷新 50 | $0 |
| Companion | 6,000 | $19/月 |
| Pro | 18,000 | $49/月 |
| Max | 60,000 | $149/月 |

WU 消耗细则见 [Work Units](/zh/core-concepts/work-units)。

## 数据与隐私

- 每位用户获得隔离的持久化沙箱卷
- API Key 存储在加密密钥库中
- 完整说明见[隐私政策](https://myrmagent.ai/privacy)
