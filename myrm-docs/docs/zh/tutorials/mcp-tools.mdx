# MCP 工具集成

## 场景

你想让 Agent 与外部服务交互 —— 查询数据库、创建 Figma 设计、管理 GitHub Issue 或调用公司内部 API。MCP（模型上下文协议）让你无需修改 Agent 核心就能接入任何兼容的工具服务器。

## 材料

- 一个 MCP 服务器的 URL 或本地安装的 MCP 服务器（许多以 npm 包形式提供）
- 服务器的连接信息（URL、认证令牌等）

## 步骤

<Steps>
  <Step title="打开 MCP 设置">
    进入 WebUI 的 **设置 → MCP 服务器**。你会看到已连接的服务器列表和 **添加服务器** 按钮。
  </Step>
  <Step title="添加服务器">
    点击 **添加服务器**，填写：
    - **名称**：一个易记的标签（如"GitHub"）
    - **类型**：SSE（远程）或 Stdio（本地进程）
    - **URL 或命令**：服务器端点或启动命令

    点击 **保存**。Myrm 会连接服务器并发现可用工具。
  </Step>
  <Step title="验证连接">
    保存后，服务器状态显示 **已连接**，并列出发现的工具。点击任意工具可查看描述和参数。
  </Step>
  <Step title="在对话中使用">
    开始新对话，让 Agent 使用工具：

    > "列出 myrm-agent 仓库中我的待处理 GitHub Issue"

    Agent 会选择合适的 MCP 工具，调用它，并展示结果。
  </Step>
</Steps>

<Note>
  **按智能体绑定**：你可以将特定 MCP 服务器绑定到特定 Agent。"数据库专家" Agent 可以访问你的 PostgreSQL MCP 服务器，而"内容创作者" Agent 连接 Figma。在 **Agent 设置 → MCP 服务器** 中配置。
</Note>

## 更快：从集成目录一键连接

许多热门服务已在内置 **集成目录** 中预配置好 —— 无需 URL、无需 Token、无需启动命令。

<Steps>
  <Step title="打开集成目录">
    进入 **设置 → 集成目录**。搜索 "Microsoft To Do" —— 中文搜 "待办" 或 "微软" 也能直接命中预配置的 **微软待办** 条目。
  </Step>
  <Step title="点击连接">
    微软待办 **无需 API 密钥、无需注册应用**：连接卡片内联说明零配置设备码登录流程，并附 **了解更多** 链接直达官方登录页。
  </Step>
  <Step title="在对话中授权">
    告诉 Agent「帮我登录 Microsoft To Do」。它会返回设备码链接，浏览器打开并输入代码即可完成 —— 之后 Agent 就能帮你创建清单、添加任务、勾选待办项。
  </Step>
</Steps>

<Note>
  **零配置是差异化能力**：Myrm 是开源 AI 助手中唯一提供预配置、免注册 Microsoft To Do 连接器的产品（OpenClaw、CoPaw、LobsterAI、jiuwenclaw 均无内置连接器）；中文用户还能用官方中文名 **微软待办** 直接发现它。
</Note>

## 交付物

一个已连接的 MCP 服务器，其工具在任何对话中都可供 Agent 使用。

## 验收标准

- [ ] 服务器在设置中显示 **已连接** 状态
- [ ] 工具被正确列出，带有描述信息
- [ ] Agent 能成功调用工具并返回结果
- [ ] 工具调用过程在对话中正确展示

## 工具很多？智能路由（而非暴力全量注入）

阿里 **SkillWeaver** 等研究表明：把上千个工具描述一次性塞进 prompt，单轮可消耗 **~88 万 token** 且选错率高。Myrm 面向 **你的** Agent Profile，走 GUI 优先的智能路由：

| 能力 | 用户能感知到的收益 |
|------|-------------------|
| **Token 预算路由**（直连工具 ≤2,700 tok） | 常用 MCP 直接可见；超大服务自动降级为可搜索技能——无需手动调参 |
| **discover → select** | Agent 按需搜索已绑定技能（`skill_search_tool` → `skill_select_tool`），不必 Turn1 加载全部 schema |
| **混合检索**（BM25 + 向量） | 即使用词与工具名不一致也能找到——中英文都稳 |
| **多技能组合** | 「下载→转换→汇报」类任务：开启 **Workflow 模式** 或用 **看板** 流水线——先规划整条链，而非一次只选一个工具 |
| **执行韧性** | 重试、验收闸、错误诊断——研究原型常缺失的生产能力 |

**无需** 自建 FAISS 索引或跑三阶段 Decompose/Retrieve/Compose 脚本。在设置里连 MCP、绑定 Agent，直接对话即可。
