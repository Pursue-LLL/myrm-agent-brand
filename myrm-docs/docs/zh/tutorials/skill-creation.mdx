# 技能制作

## 场景

你刚完成了一个复杂任务 —— 比如生成竞品分析报告。经过几轮迭代才调好格式和数据源。现在你想把这个工作流保存下来，下次（或团队其他人）一条命令就能复现，不用重新解释一遍。

## 材料

- 一段已完成且结果满意的对话
- 明确哪些部分需要参数化（如竞品名称、日期范围）

## 步骤

<Steps>
  <Step title="先完成一次成功的任务">
    与 Agent 协作，直到获得满意的结果。对话记录就是 Skill 的原材料。
  </Step>
  <Step title="让 Agent 创建 Skill">
    在同一对话中说：

    > "把这个做成 Skill。命名为'竞品分析报告'。用户需要提供竞品名称和日期范围作为输入。"

    Agent 会分析对话，提取工作流逻辑，生成 Skill 定义。
  </Step>
  <Step title="查看和编辑">
    Skill 会出现在 **设置 → 技能** 中，包含提取的提示词、参数和描述。你可以在 GUI 中直接编辑任何字段。
  </Step>
  <Step title="使用 Skill">
    在任何对话中用斜杠命令触发：

    > `/competitor-analysis-report`

    或从技能面板中选择。Agent 会加载 Skill 的指令并询问所需输入。
  </Step>
</Steps>

<Note>
  **技能进化**：随着使用，Agent 可以根据反馈和使用模式自动优化 Skill。详见[技能进化](/docs/zh/core-concepts/skill-evolution)。
</Note>

## 交付物

一个存储在 Agent 技能库中的可复用 Skill，可通过斜杠命令或 GUI 选择调用。

## 验收标准

- [ ] Skill 产出与原始对话结果一致
- [ ] 输入参数被正确提取和提示
- [ ] Skill 在设置 → 技能中可见
- [ ] 斜杠命令能正确激活 Skill
