# 技能制作

## 场景

你刚完成了一个复杂任务 —— 比如生成竞品分析报告。经过几轮迭代才调好格式和数据源。现在你想把这个工作流保存下来，下次（或团队其他人）一条命令就能复现，不用重新解释一遍。

## 材料

- 一段已完成且结果满意的对话
- 明确哪些部分需要参数化（如竞品名称、日期范围）

## 步骤

<Steps>
  <Step title="先完成一次成功的任务">
    与 Agent 协作，直到获得满意的结果。对话记录就是 Skill 的原材料。
  </Step>
  <Step title="让 Agent 创建 Skill">
    在同一对话中说：

    > "把这个做成 Skill。命名为'竞品分析报告'。用户需要提供竞品名称和日期范围作为输入。"

    Agent 会分析对话，提取工作流逻辑，生成 Skill 定义。
  </Step>
  <Step title="查看和编辑">
    Skill 会出现在 **设置 → 技能** 中，包含提取的提示词、参数和描述。你可以在 GUI 中直接编辑任何字段。
  </Step>
  <Step title="使用 Skill">
    在任何对话中用斜杠命令触发：

    > `/competitor-analysis-report`

    或从技能面板中选择。Agent 会加载 Skill 的指令并询问所需输入。
  </Step>
</Steps>

<Note>
  **技能进化**：随着使用，Agent 可以根据反馈和使用模式自动优化 Skill。详见[技能进化](/zh/core-concepts/skill-evolution)。
</Note>

## 交付物

一个存储在 Agent 技能库中的可复用 Skill，可通过斜杠命令或 GUI 选择调用。

## 验收标准

- [ ] Skill 产出与原始对话结果一致
- [ ] 输入参数被正确提取和提示
- [ ] Skill 在设置 → 技能中可见
- [ ] 斜杠命令能正确激活 Skill

## 把一套工作流做成技能包（以广告创意为例）

**技能包**是一组职责单一、彼此交接输入输出的小技能。工作流有固定阶段时，它比一个巨型提示词更合适：每个技能保持简短，Agent 只加载当前阶段需要的那一个。

示例：5 段广告创意流水线：

| 阶段 | 技能 | 产出 |
|---|---|---|
| 1 | Audience Map | 受众分层、痛点、购买触发 |
| 2 | Angle Ranker | 按漏斗阶段排序的广告角度 |
| 3 | Copy Engine | 用买家口吻写的可投放文案 |
| 4 | Visual Brief Builder | 可直接交给设计的视觉方向 |
| 5 | Variation Machine | 钩子、语气、格式的批量变体 |

五步落地：

1. 建一个 `ad-creative/` 目录，每个阶段一个 `SKILL.md`；契约保持窄：输入、步骤、输出文件、成功标准、坑。
2. 把共享状态放在一个工作区文件，如 `ad-context.md`——品牌语气、受众事实、历史优胜素材。每个阶段读写它，让上下文跨运行复利，而不是把全部内容塞进每个提示词。
3. 通过 **设置 → 技能 → 本地技能路径** 采纳该目录，或把流程描述给 Agent，用 `/learn` 起草技能。
4. 在 **Pending Evolutions** 里审阅草稿；逐项批准、编辑或拒绝。
5. 先在 **Eval Lab** 做小规模 A/B，再决定是否绑定 **Weekly Sprint** 定时任务。

<Note>
  Myrm 目前没有开箱即用的广告创意技能包。你可以组合现有的 **Social Media Strategist / Writer / Designer**，或按上面的步骤自己写 5 个技能。把「评论 MAP 换 PDF」的包当作内容，而不是经过验证的能力。
</Note>
