# 每日简报

## 场景

你是市场经理，需要每天关注行业新闻、竞品动态和社交媒体趋势。与其每天打开 10 个网站手动搜索，不如让 AI 在你上班前准备好一份简报。

## 材料

- 你想追踪的主题或竞品列表（如"AI Agent 市场"、"竞品产品更新"）
- 一个接收渠道（邮件、微信、Telegram、Slack 等）—— 首次运行可选

## 步骤

<Steps>
  <Step title="开始对话">
    打开新对话，描述你的需求：

    > "搜索 AI Agent 产品的最新新闻，总结前 5 条，整理成早报格式，包含一句话摘要和来源链接。"
  </Step>
  <Step title="查看结果">
    Myrm 使用内置的网络搜索（7 个引擎，零费用）查找相关文章，然后整理成结构化简报。
  </Step>
  <Step title="调整需求">
    调整范围、格式或重点：

    > "加上 Manus 和 OpenClaw 的社交媒体提及。顶部加一个'关键要点'板块。"
  </Step>
  <Step title="保存为技能（可选）">
    满意后，让 Agent 保存：

    > "把这个保存为名为'早间简报'的 Skill，以后可以复用。"

    Agent 会将工作流提取为可复用的 Skill，保留你的偏好参数。
  </Step>
</Steps>

## 交付物

一份结构化的每日简报，包含行业热点、竞品动态和关键要点 —— 以 Markdown 格式输出或作为工件交付。

## 验收标准

- [ ] 简报包含相关的最新新闻（不超过 24 小时）
- [ ] 附有来源链接
- [ ] 格式便于快速浏览（标题 + 一句话摘要）
- [ ] 内容与指定主题匹配
