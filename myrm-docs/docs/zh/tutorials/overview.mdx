# 实战教程

欢迎来到 Myrm 实战教程。与[使用指南](/docs/zh/guides/goal-management)（解释功能怎么配置）不同，这些教程聚焦于**如何用 AI 解决真实工作问题** —— 一步一步，有具体产出。

## 阅读方式

每篇教程遵循统一的五要素结构：

| 要素 | 内容 |
|------|------|
| **场景** | 一个你会遇到的真实工作情境 |
| **材料** | 需要准备的文件、数据或上下文 |
| **步骤** | 逐步操作指引，含截图说明 |
| **交付物** | 你将得到的具体产出 |
| **验收标准** | 如何判断结果是否正确 |

三种部署模式（本地 WebUI / Tauri 桌面端 / SaaS 云托管）的差异会在相关步骤中标注 —— 大多数教程在三种模式下操作完全一致。

## 推荐路径

<Steps>
  <Step title="完成你的第一个任务">
    从[办公文档](/docs/zh/tutorials/office-documents)开始 —— 上传文件，让 Agent 帮你写报告，验证产出。大约 5 分钟。
  </Step>
  <Step title="尝试自动化工作流">
    进入[每日简报](/docs/zh/tutorials/daily-briefing)和[定时任务实战](/docs/zh/tutorials/scheduled-automation)，体验 Myrm 的无人值守能力。
  </Step>
  <Step title="制作可复用技能">
    学习[技能制作](/docs/zh/tutorials/skill-creation)，把成功的任务沉淀为一键可用的 Skill。
  </Step>
  <Step title="接入外部工具">
    通过 [MCP 工具集成](/docs/zh/tutorials/mcp-tools)连接外部服务，赋予 Agent 超能力。
  </Step>
</Steps>
