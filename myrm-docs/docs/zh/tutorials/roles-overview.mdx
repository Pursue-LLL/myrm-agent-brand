# 岗位与行业

每个岗位的 AI 使用模式都不一样。本板块为特定职能和行业提供针对性指导。指南正在积极编写中。

## 即将推出

- **市场与内容** —— 营销策划、内容日历、竞品追踪、社交媒体自动化
- **销售与客服** —— 线索研究、方案撰写、CRM 集成、客户回复模板
- **HR 与行政** —— 简历筛选、入职清单、制度文档生成
- **工程与数据** —— 代码审查辅助、数据管线监控、文档生成
- **金融与分析** —— 报表自动化、数据提取、投研摘要

## 成熟度模型

随着你对 Myrm 的使用深入，使用方式会自然经历四个层次：

| 层级 | 阶段 | 示例 |
|------|------|------|
| **L1** | 单次任务辅助 | "帮我写这封邮件" |
| **L2** | 模板化工作流 | 为重复任务创建可复用 Skill |
| **L3** | 自动化管线 | 定时任务 + 渠道推送 |
| **L4** | 团队能力 | 共享 Agent、市场 Skill、多 Agent 编排 |

从你当前所在的层级开始即可。本板块的每篇教程都会标注适用的成熟度层级。
