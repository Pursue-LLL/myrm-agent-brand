# 数据库配置

Myrm 把全部数据放在同一个数据目录：`MYRM_DATA_DIR`（默认 `~/.myrm`）。无需外部数据库或向量服务。

| 路径 | 内容 |
|------|------|
| `data.db` | 主 SQLite 数据库 |
| `qdrant/` | 记忆检索使用的内嵌向量库 |
| `checkpoints.db` | 智能体检查点 |
| `memory/` | 记忆内容 |

同一个数据目录同一时间只能由一个运行中的 Myrm 使用，因为内嵌向量库会锁定自己的文件夹。打不开该文件夹的第二个副本会继续运行，但新记忆不会被永久保存，并会在应用内显示警告。

## 图存储（可选）

`DATABASE_URL` 指向可选的 Apache AGE（PostgreSQL）图存储。留空则图数据保存在数据目录下的 SQLite 中。

## 备份

先停止 Myrm，再复制整个数据目录：

```bash
cp -R "${MYRM_DATA_DIR:-$HOME/.myrm}" "./backups/myrm-$(date +%Y%m%d)"
```
