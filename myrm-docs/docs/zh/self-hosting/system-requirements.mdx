# 系统要求

## 最低配置

| 资源 | 要求 |
|----------|------------|
| CPU | 2 核 |
| 内存 | 4 GB |
| 磁盘 | 10 GB |
| 操作系统 | Linux、macOS 或 Windows（Docker） |
| Docker | 24+ 且含 Compose v2 |

## 推荐配置

| 资源 | 要求 |
|----------|------------|
| CPU | 4+ 核 |
| 内存 | 8+ GB |
| 磁盘 | 50+ GB SSD |
| 网络 | 稳定互联网（访问 LLM API） |

## 可选依赖

- **Qdrant** — 向量数据库，用于高级记忆检索（Docker Compose 已包含）
- **Redis** — 缓存与限流（可选）

## 部署模式一览

同一套代码库支持三种部署模式，各模式资源消耗不同。模型始终通过 API 访问（BYOK、relay 或可选的本地 Ollama），因此**任何模式都无需 GPU**。

| 模式 | 运行位置 | 资源消耗 | 你需要维护 |
|------|---------|---------|-----------|
| **本地 WebUI** | 自有机器或 NAS（Docker） | 取决于主机 CPU + 内存 | 服务、升级、备份 |
| **Tauri 桌面端** | 笔记本/台式机原生应用 | 轻量原生外壳 | 安装即可运行 |
| **云托管** | 控制平面沙箱 | 平台托管 | 无需任何维护，自备模型 API 密钥 |

## 按使用强度选配

大多数自托管场景落在轻量档。重型档仅用于团队使用或持续的多智能体负载。

| 档位 | 负载 | 推荐规格 |
|------|------|---------|
| **轻量** | 个人助理、日常对话、单智能体 | 2 核 / 4 GB / 10 GB |
| **中等** | 编码与浏览器任务、定时任务 | 4 核 / 8 GB / 50 GB |
| **重型** | 团队使用、多智能体、持续高负载 | 8 核 / 16 GB / 100 GB+ |

## 资源限制（防 OOM）

Docker Compose 自带可配置的资源限制，用于保护低配主机（NAS、老电脑）：

| 变量 | 默认值 | 含义 |
|------|-------|------|
| `MYRM_MEM_LIMIT` | `0`（不限制） | Myrm 容器最大内存，例如 `3g` |
| `MYRM_CPU_LIMIT` | `0`（不限制） | Myrm 容器最大 CPU，例如 `2.0` |

在启动前设置：

```bash
MYRM_MEM_LIMIT=3g MYRM_CPU_LIMIT=2.0 docker compose up -d
```

在 NAS 或共享主机上，务必设置 `MYRM_MEM_LIMIT`，防止智能体耗尽整台机器内存。

完整变量列表见[环境变量参考](/docs/zh/self-hosting/environment-variables)。

## 与竞品的诚实对比

各平台官方自托管最低规格（浏览器自动化对所有平台的 RAM 要求提升幅度大致相当）：

| 平台 | 最低规格 | 说明 |
|------|---------|------|
| **Myrm** | 2 核 / 4 GB / 10 GB | 无 GPU；模型走 API；资源限制可配置 |
| **MonkeyCode** | 控制台 2C/4G/40G + 开发主机 8C/16G/100G | 开发主机随团队规模扩展；本地推理可能需要 GPU |
| **OpenClaw** | 2 vCPU / 4 GB / 20 GB+（社区评估） | 官方文档仅注明 Node 运行时、未公布硬件最低要求；浏览器自动化需 4C/8G；本地模型需 16 GB+ 内存 |

来源：[MonkeyCode README](https://github.com/chaitin/MonkeyCode)（官方自托管规格）与 [OpenClaw 文档](https://docs.openclaw.ai/install)（仅 Node），OpenClaw 硬件规格为社区评估（[1](https://provision.ai/openclaw-hardware-requirements)、[2](https://clawtrust.ai/blog/openclaw-server-requirements)）。
