# 系统要求

## 最低配置

| 资源 | 要求 |
|----------|------------|
| CPU | 2 核 |
| 内存 | 4 GB |
| 磁盘 | 10 GB |
| 操作系统 | Linux、macOS 或 Windows（Docker） |
| Docker | 24+ 且含 Compose v2 |

## 推荐配置

| 资源 | 要求 |
|----------|------------|
| CPU | 4+ 核 |
| 内存 | 8+ GB |
| 磁盘 | 50+ GB SSD |
| 网络 | 稳定互联网（访问 LLM API） |

## 可选依赖

- **Qdrant** — 向量数据库，用于高级记忆检索（Docker Compose 已包含）
- **Redis** — 缓存与限流（可选）
