# Welcome to Myrm

Myrm is an **open-source AI agent workspace**: the WebUI, API server, Tauri desktop app, and the agent harness runtime are MIT-licensed; only the optional SaaS control plane is proprietary. You get persistent per-user sandboxes, cross-session memory, and a GUI-first experience with 100+ LLM models, 26 messaging channels, and three deploy modes — local WebUI, Tauri desktop, or SaaS cloud.

## Deployment Options

| Mode | Description | Cost |
|------|-------------|------|
| **Local WebUI** | Browser-based, self-hosted on your machine | Free (BYOK) |
| **Tauri Desktop** | Native desktop app with embedded backend | Free (BYOK) |
| **SaaS Cloud** | Managed infrastructure with Work Units billing | Free tier + Paid plans |

All three modes share the same codebase and feature set. Your data and configuration are portable between modes.

## Token Efficiency

Myrm's turn-one tool disclosure starts at about **1,765 tokens** in our benchmark profile (about 2,167 with a fuller toolset) — materially below loading every tool up front. With prompt caching, effective cost can drop further. Treat these as measured defaults for the stated toolset, not a universal guarantee: your enabled tools, skills, and model change the number.

## What is open

The **WebUI, API server, agent harness, and Tauri desktop shell are MIT-licensed**. The optional SaaS control plane (multi-tenant billing, LLM relay, fleet management) is proprietary; you do not need it to run the product yourself.

That split is deliberate: the part that touches your files, memory, skills, and model keys can be audited, forked, and self-hosted. See [Product Architecture](/getting-started/product-architecture) for the layer-by-layer contract.
