# Tutorials

Welcome to the Myrm hands-on tutorials. Unlike the [Guides](/docs/guides/goal-management) (which explain *how features work*), these tutorials show you **how to solve real work problems with AI** — step by step, with concrete deliverables.

## How to Read

Each tutorial follows a consistent five-element structure:

| Element | What it covers |
|---------|---------------|
| **Scenario** | A real work situation you'll recognize |
| **Materials** | Files, data, or context you need to prepare |
| **Steps** | Click-by-click walkthrough with screenshots |
| **Deliverable** | The concrete output you'll produce |
| **Acceptance** | How to verify the result is correct |

Deployment differences (Local WebUI / Tauri Desktop / SaaS Cloud) are noted where relevant — most tutorials work identically across all three modes.

## Suggested Path

<Steps>
  <Step title="Complete Your First Task">
    Start with [Office Documents](/docs/tutorials/office-documents) — upload a file, ask the agent to write a report, and verify the output. Takes about 5 minutes.
  </Step>
  <Step title="Try Automated Workflows">
    Move to [Daily Briefing](/docs/tutorials/daily-briefing) and [Scheduled Automation](/docs/tutorials/scheduled-automation) to see how Myrm works unattended.
  </Step>
  <Step title="Build Reusable Skills">
    Learn to [create your own Skills](/docs/tutorials/skill-creation) from successful tasks, so you never repeat the same setup.
  </Step>
  <Step title="Extend with Tools">
    Connect external services through [MCP Tools](/docs/tutorials/mcp-tools) to give your agent superpowers.
  </Step>
</Steps>
