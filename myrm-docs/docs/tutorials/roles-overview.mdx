# Roles & Industries

Every role has different AI adoption patterns. This section provides tailored guidance for specific job functions and industries. Playbooks are being actively developed.

## Maturity Model

As you adopt Myrm, your usage naturally progresses through four levels:

| Level | Stage | Example |
|-------|-------|---------|
| **L1** | Single-task assistance | "Help me write this email" |
| **L2** | Template workflows | Reusable Skills for recurring tasks |
| **L3** | Automated pipelines | Scheduled tasks with channel delivery |
| **L4** | Team capability | Shared agents, marketplace Skills, multi-agent orchestration |

Start where you are. Each tutorial in this section will note which maturity level it addresses.
