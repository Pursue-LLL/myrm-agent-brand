# ワークスペースのスマート整理

散らかった chat workspace や vault ディレクトリを整理します。Agent は**移動プラン**を生成し、あなたが表でレビューしてから実行またはロールバックします — **黙ってファイルを移動することはありません**。

これは WeChat 公式アカウントのドラフト配信と同じく **file-centric + HITL** パターンです。Agent が plan アーティファクトを書き、あなたは WebUI で確認します。

<Note>
**Turn Undo** が戻すのは会話 / ツールのスナップショットで、**ワークスペースのファイル移動は戻しません**。整理パネル上の **前のタスクをロールバック** を使ってください。
</Note>

## 適用できるシーン

- 長い調査セッションのあと、同じディレクトリにファイルが積み上がった
- Obsidian の vault サブディレクトリをサンドボックスに繋ぐ前にアーカイブしたい
- workspace 内の Downloads のような一時ファイルが堆積した

## 使い方

### 方法 A — ファイルツリー（推奨）

1. チャットのサイドバーで **ワークスペースのファイルブラウザ** を開きます
2. **ディレクトリ**を右クリック → **AI にこのディレクトリを整理させる**
3. チャットの入力欄に整理用プロンプトがプレフィルされるので、送信します（変更も可、例「プロジェクトごとに分類して」）

### 方法 B — 会話で指示

そのまま Agent に伝えてください。

> workspace-auto-organizer を使って `my-folder/` 以下のファイルを整理し、レビュー用に organize-plan.json を出力して。

## フロー

### ステップ 1 — Agent がスキャンしてプランを書く

**workspace-auto-organizer** プリセットスキルは次のことを行います。

- `glob_tool` で範囲をスキャン（最大 500 ファイル）
- サンプリングして分類を推定
- `{scope}.organize-plan.json` に書き出す（各項目に `src` / `dst` / `reason`）
- `mv` や shell での移動を**禁止**

### ステップ 2 — WebUI でレビュー

プランがチャットアーティファクトとして現れたら:

1. アーティファクトカードの **Review organize plan** をクリックします
2. 移動先パスを編集する、または異議のある行を削除します
3. **Validate**（dry-run）をクリックして、衝突とスコープルールを確認します

### ステップ 3 — 実行

**Apply moves** をクリックします。サーバーは:

- ワークスペース書き込みと同じ安全スタックでパスを検証します
- 一括移動し、ロールバック用の **OrganizeJob** を記録します
- ファイル名が変更された場合は Markdown 内の `[[wikilink]]` を更新します

Apply / Rollback の後はファイルツリーが自動更新されます（サイドバーの watch、または整理パネルからの更新）。

### ステップ 4 — 必要ならロールバック

同じパネルの **Rollback last job** をクリックします。タスクログから移動を復元します — **Turn Undo ではありません**。

全ファイルを復元できない場合（途中で手動削除など）、**部分ロールバック** が通知されます。ファイルツリーを確認して残りを手動で処理してください。

## 安全性と設計

| 設計 | 理由 |
|------|------|
| Harness に organize 用のメタツールを置かない | Agent のツール schema を安定させ、Prompt Cache を保つため |
| スキルが直接 mv するのを禁じる | HITL を強制し、誤削除リスクを下げるため |
| OrganizeJob でロールバックする | Turn Undo は任意のファイル移動をカバーしないため |
| スコープと深さの制限 | プランがあなたが許可したサブディレクトリの外へ出られないようするため |

## トラブルシューティング

| 症状 | 対処 |
|------|------|
| Validate が `dst_exists` を出す | 移動先が既にあります — プランを編集するか行を削除します |
| Validate が `mtime_mismatch` を出す | プラン生成後にソースファイルが変更されました — プランを再生成します |
| ロールバックボタンが無い | この workspace に実行済みタスクが無い、または既にロールバック済みです |
| Turn Undo でファイルが戻らない | 想定どおりです — 整理パネルの **ロールバック** を使ってください |
| Validate が `duplicate_src` を出す | プラン内で同じソースパスが 2 回出ています — 行を削除するか修正します |
| ファイルツリーが更新されない | ワークスペースのサイドバーに切り替えます。Apply 後は自動で更新されます |
