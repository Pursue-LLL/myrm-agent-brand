# ワークスペースのファイルプレビュー

ワークスペースのファイルブラウザは、エージェントのサンドボックス内のファイルを表示します。任意のファイルをクリックすると、Myrm が表示方法を自動で決めます — **テキストはテキストとして描画、リッチメディアはワークスペースを離れずにプレビューできます**。

## アプリ内プレビューの種類

| ファイル種別 | 挙動 |
|--------------|------|
| PDF | react-pdf によるインライン描画（スクロール・ズーム可） |
| 画像（PNG / JPEG / WebP など） | アプリ内でフルサイズ描画 |
| 動画 / 音声 | ストリーミング URL ベースのアプリ内プレーヤー |
| SVG | インラインのベクター描画 |
| Markdown / コード / プレーンテキスト | 既存のテキスト閲覧・編集 UI |
| 未対応・不明のバイナリ | ダウンロードにフォールバック — 文字化けは絶対に出しません |

## スマートなテキスト / バイナリ判定

Myrm は推測で決めません。バックエンドがスキャン時に各ファイル項目へ権威ある `is_text` フラグ（I/O のない拡張子判定）を付け、フロントエンドはそれに従ってルーティングします。

- **テキストファイル**はサイズ上限つきの配信で、超大なログでもページが固まりません。
- **バイナリファイル**は HTTP Range による全量ストリーミング転送 — 切り取られた断片ではなく完全な PDF が返り、プレビューもダウンロードも完全です。

未知の拡張子も安全です。バックエンドがテキストと判定できないファイルは一律バイナリとして扱い、ダウンロードを提供します（文字化けとして描画することはありません）。

## 安全なダウンロード

ダウンロードのレスポンスではヘッダー注入を遮断し（CR/LF を除去）、非 ASCII のファイル名は RFC 5987 でエンコードします — 中文・韓国語・絵文字のファイル名でも、どのプラットフォームでも正しくダウンロードできます。

## プレビューカーネル

アーティファクトのレンダラーはチャットとワークスペースのファイルブラウザで共有されます。PDF・文書・表・画像・動画・音声・SVG・インタラクティブ UI のプレビューが同じ描画パイプラインを使います。ワークスペース側はこれにバイナリのストリーミングと安全なレスポンスヘッダーを重ねています。
