# リサーチワークベンチ

リサーチワークベンチは **3 ペイン並列のインターフェース**で、資料の整理・AI との対話・生成された成果物のプレビューを同じビューで行えます。**ローカル WebUI**・**Tauri デスクトップ**・**クラウドホスト展開**のいずれでも動作します。

## レイアウト

| ペイン | 用途 |
|--------|------|
| **左ペイン — 資料プール** | ナレッジベースから概念を検索し、ファイルをアップロードして、研究コンテキストとしてチェックします。 |
| **中央ペイン — 対話** | 設定済みの任意のエージェントと対話します。選択した資料は自動でコンテキストへ注入されます。 |
| **右ペイン — 成果物** | 生成された成果物（ドキュメント、資料、レポート）をプレビューし、ダウンロードやナレッジベースへの保存ができます。 |

モバイルデバイス（ビューポート幅 ≤ 768px）では、3 ペインは自動的に **タブ切替ナビゲーション**へ切り替わります。

## リサーチワークベンチを開く

サイドバーで「リサーチワークベンチ」をクリックするか、**/research** へ直接アクセスします。

## 研究資料を追加する

### ナレッジベースから追加

1. 資料プール上部の **ナレッジベースから** ボタンをクリックします。
2. キーワードでナレッジベースの概念を検索します。
3. 概念名をクリックすると追加されます。追加済みの概念は自動的に「追加済み」と表示されます。

### ファイルをアップロード

1. 資料プール上部の **アップロード** ボタンをクリックします。
2. ファイルを選択します（PDF、DOCX、TXT、MD、CSV、XLSX、PPTX に対応）— 一度に最大 20 ファイル、1 ファイルあたり最大 50MB。
3. アップロードしたファイルが資料プールに現れ、チェックして使えます。
4. 大きなドキュメント（> 100KB）は自動的にナレッジベースへ入れ、スマート RAG 検索で活用され、LLM token を節約します。
5. 重複ファイルは SHA-256 ハッシュで自動的に検出されスキップされます。

## チェックと解除

各資料の前に **チェックボックス** があります。選択した資料は、`@wiki_concept` または `@wiki_raw_file` の参照として AI 対話のコンテキストへ自動注入されます。

- **全選択 / 全解除** — 全資料をワンクリックで切り替え
- **個別切り替え** — 資料の行をクリックすると選択状態が切り替わります

ナレッジベース型の参照のみ同期機構が管理します。チャット入力欄で手動追加した他の `@` 参照（`@file.pdf` など）は保持されます。

## コンテキスト付きで対話する

中央ペインは完全なチャット画面です。資料プールで資料を選ぶと、その内容が次のメッセージへ注入されます。エージェントは選択した資料すべてを参照し推論できます。

組み込みの `builtin-researcher` リサーチエージェント、または任意のカスタムエージェントを利用できます。

## 成果物の閲覧と書き出し

エージェントが成果物（レポート、資料、ドキュメント、マインドマップ、音声など）を生成すると、右ペインに現れます。

- **プレビュー** — レンダリング結果。シンタックスハイライト、インタラクティブな図表、メディア再生に対応
- **ダウンロード** — 成果物をローカルへ保存
- **ナレッジベースへ保存** — 成果物をナレッジベースへ永続化し、後から引用可能にする
- **タブ切替** — 複数の成果物をタブで切り替えて閲覧

### 対応する出力タイプ

| タイプ | 表示方法 | プロンプト例 |
|--------|----------|--------------|
| **マインドマップ** | インタラクティブな Mermaid SVG — 拡大 / フルスクリーン / SVG ダウンロード / 凡例フィルタ | 「重要な発見のマインドマップを描いて」 |
| **音声** | 内蔵の音声プレーヤー | 「要約を読み上げて」 |
| **ドキュメント** | 整えられた Markdown + コードハイライト | 「調査レポートを書いて」 |
| **資料** | PPTX のプレビューとダウンロード | 「このレポートから PPT を作って」 |
| **HTML** | サンドボックス化された iframe プレビュー | 「インタラクティブなダッシュボードを作って」 |
| **図表** | Mermaid 図（フローチャート / シーケンス図 / ガントチャートなど 13+ 種） | 「タイムライン図を描いて」 |
| **コード** | シンタックスハイライト + 言語自動判定 | 「Python の分析スクリプトを書いて」 |
| **表** | CSV / Excel のテーブルビュー | 「データを CSV へ書き出して」 |

## リサーチ → ノート → 資料のフルチェーン

リサーチワークベンチは、リサーチから納品までのワークフローを画面内で完結できます。

1. **リサーチ** — 資料プールで資料をチェックし、エージェントに深掘り調査させます。`builtin-researcher` エージェントは HITL の計画確認に対応しており、実行前に研究計画をレビュー・編集できます。
2. **ノートとして保存** — エージェントがレポートを出したら、メッセージの操作バーにある **ナレッジベースへ保存** ボタンをクリックします。ノートには来歴情報（元の対話、メッセージ ID、タイムスタンプ）が付くため、元の対話まで遡れます。
3. **編集** — 保存したノートをナレッジベースの概念パネルで開き、Markdown の内容を直接編集できます。
4. **資料を生成** — 対話の中で「このレポートから PPT を作って」と言います。`office-document` スキルが `python-pptx` を使い、サンドボックスで完全編集可能な `.pptx` ファイルを生成します。各ページの内容・レイアウト・図表・スタイルはエージェントが自由に制御でき、固定テンプレートに縛られません。
5. **ダウンロード** — 生成された資料は右ペインの成果物エリアに現れ、そのままダウンロードできます。

この会話型ワークフローは**固定パイプラインより柔軟**です。どの段階でも割り込み、特定章の修正、資料スタイルの差し替え、任意ノードからの再スタートが可能です。すべて自然言語で操作できます。

## 複数文書横断分析

複数のファイルを資料プールへアップロード（またはナレッジベースへインポート）して全選択し、分析系の質問を投げられます。

- 「これらのレポートに共通する主張は？」
- 「これらの文書の間にはどんな矛盾がある？」
- 「『AI は 30% の雇用を置き換える』という主張の初出はどのレポート？」

エージェントは選択した文書をすべて読み、共通点・矛盾・引用の出所を特定し、構造化された分析レポートを生成します。主な特徴:

- **クリック可能な引用** — 帰属する引用はすべて Citation Source Jump 経由で原文段落へリンクし、クリックでハイライトされた元のコンテキストを確認できます
- **並行分析** — 文書が多い場合、エージェントが各文書の分析を子エージェントへ並行委譲し、結果を統合できます
- **情報完全性の担保** — 組み込みの完全性ルールにより、すべての主張が証拠に基づくことを確認し、ソース間の矛盾は明示されます
- **柔軟な分析の切り口** — 事前定義された分析テンプレートはありません。トレンド・タイムライン・感情・リスク要因など何でも聞け、エージェントが分析戦略を動的に調整します

## レスポンシブデザイン

ワークベンチは画面サイズへ自動対応します。

| 画面 | レイアウト |
|------|-----------|
| デスクトップ（> 768px） | 3 ペイン幅をドラッグで調整可能 |
| モバイル（≤ 768px） | タブ切替ナビゲーション：資料 / 対話 / 成果物 |
