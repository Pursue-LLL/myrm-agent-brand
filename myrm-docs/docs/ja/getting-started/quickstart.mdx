# クイックスタート

お好みのデプロイ方法を選んで始めましょう。

<Note>
**他のエージェントからの乗り換えですか？** 先に[競合比較](/getting-started/competitor-comparison)をお読みください——Hermes・OpenClawなどをMyrmに一箇所で対応付けています。Myrmは**SaaS**・**セルフホストWebUI**・**デスクトップ**から選べます。下のいずれか1ルートを選んでください。スキルとメモリはGUI移行ウィザードで引き継げます（デスクトップ / ローカルWebUI）。
</Note>

## SaaSクラウド（最速）

インストール不要です。[app.myrmagent.ai](https://app.myrmagent.ai/auth/login)でアカウントを作るだけです。

## ローカルデプロイ（Docker）

<Steps>
  <Step title="リポジトリをクローン">
    ```bash
    git clone https://github.com/Pursue-LLL/myrm-agent.git
    cd myrm
    ```
  </Step>
  <Step title="サービスを起動">
    ```bash
    docker compose up -d
    ```
  </Step>
  <Step title="UIにアクセス">
    ブラウザで[http://localhost:3000](http://localhost:3000)を開きます。
  </Step>
</Steps>

## デスクトップアプリ（Tauri）

[GitHub Releases](https://github.com/Pursue-LLL/myrm-agent/releases)からお使いのプラットフォーム向け最新版をダウンロードしてください。

| プラットフォーム | ダウンロード |
|----------|----------|
| macOS（Apple Silicon） | `.dmg` |
| macOS（Intel） | `.dmg` |
| Windows | `.exe`（セットアップウィザード）/ `.msi`（Enterprise） |
| Linux | `.AppImage` |

## 次のステップ

セットアップが終わったら：

1. **最初のエージェントを設定** — モデルを選びツールを用意します
2. **会話を始める** — タスクを説明してエージェントに任せます
3. **メモリを覗く** — エージェントがセッションをまたいで学ぶ様子を見ます

<Tip>
**自動レベルアップ**：MyrmはAI活用レベル（L1–L5）の到達を追跡します。初チャット・初ツール利用・初承認などのマイルストーンで自動レベルアップし、上位機能が解放されます。手動操作は不要です。
</Tip>
