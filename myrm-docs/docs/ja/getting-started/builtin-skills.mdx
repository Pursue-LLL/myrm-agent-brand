# 組み込みスキルと出荷時デフォルトセット

Myrm を新しくインストールすると、**設定不要**でそのまま高频のオフィス業務を始められます。文書を読む、データ分析、Web 調査、Word / PPT / Excel の生成、PDF の書き出しです。

## 出荷時に有効な 5 つのスキル

| スキル | 典型的な用途 |
|--------|--------------|
| **データ分析**（`data-analysis`） | 表形式データの整備と分析、結論とグラフの出力 |
| **ディープリサーチ**（`deep-research`） | 多段の検索、クロス検証、出典付きの調査レポート |
| **文書抽出**（`document-extraction`） | PDF / HTML / Markdown から構造化された内容と表を抽出 |
| **オフィス文書生成**（`office-document`） | **Excel (.xlsx)、PowerPoint (.pptx)、Word (.docx)** の生成と編集 |
| **PDF 生成**（`pdf-generator`） | 請求書、監査報告書、分析報告書などの高忠実 PDF（中文描画対応） |

<Note>
**なぜ全スキルのプリセットではなく、この 5 つなのか？**
出荷セットは意図的に**小さく正確に**保っています。業界を横断して使えるローカル処理型のワークフローだけを置き、初回の対話に大量のスキル説明を押し込んでコストと誤発動を避けるためです。残りのスキルはいつでも自分で有効化できます。
</Note>

## 知っておくべき 3 つの挙動

<Steps>
  <Step title="新規インストール時のみ有効">
    デフォルトセットは**システムが初めてスキル設定を作る際にのみ**書き込まれます。すでに使っているアカウントの有効 / 無効の選択は**デフォルト値によって決して上書きされません** — アップグレードやスキル追加でも既存の設定はそのままです。
  </Step>
  <Step title="デフォルトセットは実在するスキルに紐づく">
    デフォルト一覧に残るのは**現在実際に存在する**スキルだけです。後のバージョンで削除・改名されたスキルは自動的にデフォルトセットから外れ、無効になった項目は残りません。
  </Step>
  <Step title="いつでも無効にでき、勝手に復活しない">
    **設定 → スキル** で任意のデフォルトスキルを無効にすると、停止リストに記録され、**以後の再起動やアップグレードで自動的に有効化されることはありません**。
  </Step>
</Steps>

## 有効化の変更方法

1. **設定 → スキル** を開きます（サイドバーの「スキル」入口からも開けます）。
2. 上部の「装備済み」タブに現在の有効数が表示されます。プリセットスキルのリストでチェック / チェックを外すだけです。
3. 有効化は**次のメッセージから**反映されます — スキルは「名前 — 説明」の形式で利用可能なカタログに入り、モデルはタスクが合致した時点で詳細手順を必要な分だけ読み込みます。

<Note>
**無効にしたのに復活しないのはなぜ？**
停止操作は個人設定に書き込まれ、任意のデフォルト策略より優先されます。UI が表示する有効状態とバックグラウンドの実際の状態は常に一致しており、「UI では消えているのに裏では動いている」状態は存在しません。
</Note>

## 競合との差

- **OpenClaw / Hermes**: スキルを**デフォルトで全有効** — 能力は多い反面、初回のコンテキストコストが大きく、弱いモデルが誤ってツールを起動しやすい。
- **OpenCode / Pi**: アーキテクチャは同样に潔癖（カタログをメッセージに入れ、本文は按需読み込み）ですが、**オフィス文書の産出には外部ツールを自分で組み込む必要があります**。
- **Myrm**: **素手でも溢れもしない** — 出荷時から精选された 5 つの汎用オフィススキル（Word / PPT / Excel 生成を含む）を備え、**すべて可視化され、ワンクリックで無効化できます**。
