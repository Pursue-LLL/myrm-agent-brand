# Myrm へようこそ

Myrm は**オープンソース**の AI Agent ワークスペースです。WebUI・API サーバー・Tauri デスクトップ・Agent Harness ランタイムは MIT ライセンスのオープンソースで、オプションの SaaS 制御プレーンのみ proprietary コンポーネントです。永続化された per-user サンドボックス、セッションをまたぐ記憶、GUI ファーストの体験を手にされ、100 以上の LLM モデル、26 のメッセージチャネル、3 つのデプロイモード（ローカル WebUI / Tauri デスクトップ / SaaS クラウド）に対応します。

## コア能力

| 能力 | 説明 |
|------|------|
| **目標管理** | 目標を定義し、4D 予算制御・受入基準・自律実行で進めます |
| **カンバン** | タスク管理を可視化し、DAG 依存・優先度スケジューリング・ゾンビタスク検出を扱います |
| **サブエージェント・オーケストレーション** | 6 モード（Spawn / Chain / Batch / DAG / Verified / Swarm）、ゼロトラスト検証、UI ブラックリスト、スマート予算降格、途切れのない HITL コンテキスト注入 |
| **コンテキストエンジニアリング** | 5 層の圧縮パイプライン、可逆アーカイブ、Prompt キャッシュ |
| **26 チャネル** | WeChat、Telegram、Discord、Slack、メール、SMS — どのプラットフォームからでもどの Agent とでも対話 |
| **6 層のセキュリティ** | 多層防御: 予算制御、権限、ループ検知、PII 保護、監査追跡 |
| **Computer Use** | ネイティブの画面制御でデスクトップを自動化（macOS + Linux） |
| **Web 検索 + 取得** | 7 つの検索エンジン、複数クエリの統合と重複排除 + 3 段階のローカル取得と DOM 剪定 — 月額 $0 |
| **音声対話** | 7 種の TTS + 5 種の STT エンジン、無料のローカル方案を含む |
| **成果物のデプロイと共有** | 16 以上のプレビュー形式（CSV/XLSX の並べ替え・検索・書き出し対応インタラクティブ表ビュー）、Vercel ワンクリックデプロイ、1〜30 日で失効する読み取り専用共有リンク（任意のパスワードゲート、ワンクリック失効で即 404）、複数ファイルの静的パッケージ、デプロイ事前チェック、Git 不要 |

## デプロイオプション

| モード | 説明 | コスト |
|--------|------|--------|
| **ローカル WebUI** | ブラウザベース、自分のマシンでセルフホスト | 無料（BYOK） |
| **Tauri デスクトップ** | バックエンドを内包するネイティブデスクトップアプリ | 無料（BYOK） |
| **SaaS クラウド** | ホスト型インフラ、Work Units 課金 | 無料枠 + 有料プラン |

3 つのモードは同一のコードと機能セットを共有します。データと設定はモード間で移行できます。

## Token 効率

ベンチマーク構成では、Myrm の初回ツール開示は約 **1,765 tokens**（より完全なツールセットでは約 2,167）で、すべてのツールを最初に並べる方式より明確に少なくなります。Prompt キャッシュと組み合わせれば、実効コストはさらに下がります。これらは特定のツールセットにおける実測の初期値であり、普遍的な保証ではありません。有効化するツール、スキル、モデルによって数値は変わります。

## 何がオープンソースか

**WebUI、API サーバー、Agent Harness、Tauri デスクトップシェルは MIT ライセンス**です。任意の SaaS 制御プレーン（マルチテナント課金、LLM リレー、フリート管理）は専有コンポーネントで、自分で製品を動かすのに必須ではありません。

この分割は意図的です。ファイル、記憶、スキル、モデルキーに触れる部分は、監査・fork・セルフホストが可能です。レイヤーごとの契約は[製品アーキテクチャ](/ja/getting-started/product-architecture)を参照してください。
