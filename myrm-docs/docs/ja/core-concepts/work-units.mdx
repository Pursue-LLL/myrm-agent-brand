# Work Units とコスト管理

Myrm はすべてのデプロイモードをカバーする完全なコスト管理体系を提供します — SaaS の Work Unit 課金、ローカル BYOK の予算制御、そして全チェーンの分析ダッシュボードまで。

## Work Units（SaaS）

Work Unit は SaaS プラットフォームにおけるすべての使用量の統一計量単位です。

### WU を消費する操作

| 操作 | レート |
|------|--------|
| LLM 入力 Token | モデルにより異なる |
| LLM 出力 Token | モデルにより異なる |
| ツール実行 | 回数ごと |
| サンドボックス稼働時間 | 分単位 |
| ファイルストレージ | GB/月 |

### プラン

| プラン | WU/月 | 価格 | 追加 |
|--------|-------|------|------|
| Free | 600 | $0 | 毎日 +50 リフレッシュ |
| Companion | 2,500 | $19/月 | 無制限 Agent |
| Plus | 5,000 | $42/月 | Cron 自動化 |
| Pro | 12,000 | $49/月 | 7 日間の無料トライアル |
| Max | 22,000 | $149/月 | 専任サポート |

## Token 効率

Myrm の最適化済みシステムプロンプトは約 1,765 tokens のみで、同種プラットフォームでは 15,000+ に達することもあります。Prompt キャッシュと組み合わせれば、有効コストは最大 97% まで下がります。

## ローカル / デスクトップ

ローカル WebUI と Tauri デスクトップは WU を消費しません。BYOK（自分の API Key）で LLM 提供者に直接支払う形です。

## 予算制御

Myrm には 3 次元の予算システムが内蔵されており、意図しないコストから守ります。

### 3 つの次元

| 次元 | 制限の範囲 | 例 |
|------|-----------|-----|
| セッションごと | 1 会話あたりのコスト上限（`session_id` 単位のタブ物理分離で並行干渉なし） | 1 チャットあたり $2.00 |
| 日ごと | その日の合計消費上限（UTC ゼロ点で精密にリセットし、再起動後も復元） | 全チャット合計 $10.00/日 |
| 呼び出しごと | 1 回の LLM 呼び出しのコスト上限 | API 呼び出しごとに $0.50 |

### 4 段階の段階的対応

1. **OK** — 正常動作
2. **WARNING** — 上限間近（既定 80%）で Toast 通知し、非破壊的なヒントを注入
3. **FINALIZATION** — 15% の予備枠を残して通し、Agent に完了成果をまとめさせて半成品コードを防止
4. **EXCEEDED** — ハード遮断で停止し、手動で調整 or リセットするまで新規メッセージは遮断

**設定 > システム > 予算ポリシー** で設定します。予算実行は末尾の prompt injection 方式で行うため、Prompt キャッシュの接頭辞稳定性（KV Cache 命中率 99%+）を壊しません。またフロントエンド複数タブのセッション台帳を分離し、タブ切り替えや並行実行が互いをリセットし合うことも防ぎます。

## 企業組織の予算（クラウドのみ）

クラウド配置の企業組織管理者は、チーム単位の月間 WU 予算とアラート閾値を設定できます（月 1 回トリガー）。

### 仕組み

1. 管理者が月間 WU 予算とアラート閾値を設定（例: 10,000 WU、80% でアラート）
2. システムが全メンバーの WU 消費をリアルタイムに追跡
3. 組織合計が閾値を超えると、プラットフォーム運用通知チャネル（Slack または Webhook）へ 1 回アラートを送信
4. アラートは毎月冪等 — アラートストームは発生しません
5. 閾値を変更するとアラートフラグがリセットされ、新しい閾値が即時反映されます

組織予算は可視化とアラートの用途であり、消費上限ではありません。超過しても利用はブロックされず、メンバー単位の上限もありません。管理者は企業設定の用量ページで予算進捗・メンバー順位・カテゴリ別の割合を確認できます。

### 用量サマリー API

`/api/enterprise/org/{org_id}/usage-summary` エンドポイントが詳細な内訳を返します。

- **メンバー単位** — 各チームメンバーの今月の消費量
- **カテゴリ単位** — LLM 出力、ツール実行など
- **用量比率** — 現在の消費量と月間予算の比較
- **予算状態** — 閾値を発動したかどうか

この機能はコントロールプレーンのクラウド企業配置でのみ利用できます。

## コスト分析ダッシュボード

**設定 > システム > 用量統計** で完全なコスト分析パネルを確認できます。

### ダッシュボードの内容

- **グローバル概要** — 総呼び出し回数、Token 使用量（7 種）、総コスト、キャッシュ命中率
- **日次トレンド** — 7 日または 30 日の Token 使用量とコストの時系列
- **モデル内訳** — 利用したモデルごとの呼び出し回数・Token 数・コスト
- **ルーティング分析** — スマートルーティングがタスクを各階層（シンプル/標準/推論）へどう配分したか
- **ルーティング削減試算** — スマートルーティングを使わなかった場合の費用と実際の費用の差
- **キャッシュ削減** — キャッシュで浮いた金額とキャッシュ中断の診断
- **アクティビティヒートマップ** — 1 週間のうちあなたが活動しやすい時間帯の分布
- **Top セッションランキング** — コストの高い対話の順位
- **セッションのドリルダウン** — 任意のセッションをクリックして Token / ツール / タイムラインを詳細に確認

### メッセージごとのリアルタイムコスト

AI 回答の横には**水滴アイコン**が表示され、その回答にかかる具体的なコストをリアルタイムで表示します（キャッシュ削減率を含む）。**設定 > 個人 > コスト概算を表示** で有効化できます。

### コンテキスト使用リング

メッセージ入力欄の横にあるリング表示が、現在のモデルのコンテキストウィンドウ使用率をリアルタイムで示し、使用率に応じて色が変わります。

- **緑** — 健康（<75%）
- **琥珀** — 上限間近（75-90%）
- **赤** — 臨界（>90%）
