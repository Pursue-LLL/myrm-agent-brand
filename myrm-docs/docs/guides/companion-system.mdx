# AI Companion System

The companion system transforms your agent into a virtual companion with personality, emotional awareness, and a gamified growth system.

## Features

<CardGroup cols={2}>
  <Card title="15 Species" icon="paw">
    Choose from 15 companion species, each with unique traits and evolution paths.
  </Card>
  <Card title="Emotional Awareness" icon="heart">
    Companion detects conversation tone and adapts its responses accordingly.
  </Card>
  <Card title="Growth System" icon="arrow-up">
    Companions level up through interactions, unlocking new abilities and personality traits.
  </Card>
  <Card title="Adaptive Style" icon="comment">
    Communication style evolves based on your relationship history and preferences.
  </Card>
</CardGroup>

## Configuration

1. Navigate to **Settings > Companion**
2. Select a companion species
3. Customize personality traits
4. Enable emotional awareness toggle

## How It Works

The companion system adds an emotional intelligence layer to the agent:

- Analyzes conversation sentiment and context
- Adjusts response tone, vocabulary, and engagement level
- Tracks relationship progression over time
- Provides encouragement during long tasks and celebrates completions

The companion personality is injected as part of the agent's system prompt, compatible with all prompt modes and model configurations.
