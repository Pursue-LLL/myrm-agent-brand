## 개요

MyrmAgent는 별도의 페이지가 필요 없이 사이드바에 직접 통합된 포괄적인 채팅 기록 관리 시스템을 제공합니다. 모든 대화는 한 곳에서 정리되고, 검색 가능하며, 내보낼 수 있습니다.

## 전체 텍스트 검색(Cmd+K)

앱 어디에서나 **⌘+K**(macOS) 또는 **Ctrl+K**(Windows/Linux)를 눌러 전역 검색 대화 상자를 엽니다.

- **즉각적인 결과**: 디바운싱된 검색 쿼리는 백엔드 `/chats/search` API
- **시간 범위 필터링**: 오늘, 이번 주, 이번 달 또는 이번 분기로 결과 범위를 좁힙니다.
- **스니펫 강조표시**: 검색결과에서 일치하는 텍스트가 강조표시됩니다.
- **이동하려면 클릭하세요**: 결과를 선택하면 채팅으로 바로 이동하고 일치하는 메시지가 강조표시됩니다.

## 날짜 그룹화 기록

대화는 자동으로 시간 기반 섹션으로 그룹화됩니다.

| Group | Description |
|-------|-------------|
| **Today** | Sessions from the current day |
| **Yesterday** | Sessions from the previous day |
| **Previous 7 Days** | Sessions within the past week |
| **Previous 30 Days** | Sessions within the past month |
| **Older** | Everything before 30 days |

각 그룹은 축소/확장될 수 있으며 축소된 상태는 `localStorage`을 통해 세션 전반에 걸쳐 지속됩니다.

## 고정 및 드래그 앤 드롭 재정렬

- 빠른 액세스를 위해 **대화를 사이드바 상단에 고정**
- DnD-Kit SortableContext를 사용하여 고정된 항목을 **끌어서 놓기**하여 재정렬
- **단축키**(숫자 키)를 사용하면 고정된 대화로 빠르게 이동할 수 있습니다.

## 일괄 작업

한 번에 여러 대화를 선택하려면 일괄 모드로 전환하세요.

1. 사이드바 헤더에서 배치 모드를 전환합니다.
2. 개별 채팅을 선택/선택 취소하거나 '모두 선택'을 사용하세요.
3. **일괄 내보내기**: 선택한 채팅에서 "내보내기"를 클릭하고 형식(마크다운/JSON/HTML)을 선택하면 모든 대화가 ZIP 다운로드로 패키징됩니다.
4. **일괄 삭제**: 삭제된 항목은 **휴지통**으로 이동합니다(복구와 함께 일시 삭제).

### 일괄 내보내기 기능

| Feature | Description |
|---------|-------------|
| **3-concurrent processing** | Exports 3 chats simultaneously, ~3x faster for large batches |
| **Auto retry on failure** | Failed exports are retried once automatically |
| **Date-based folders** | ZIP organizes chats by date, e.g. `2026-07-15/Chat Title.md` |
| **Real-time progress bar** | Shows current progress and the chat being processed |
| **Cancelable** | Cancel anytime during export without waiting for completion |
| **Fault-tolerant** | Individual failures don't block the batch; summary reports success/failure counts |

## 대화 내보내기

네 가지 형식으로 내보내려면 대화를 마우스 오른쪽 버튼으로 클릭하세요.

- **마크다운** — 메시지 형식으로 `.md` 파일 정리
- **HTML** — 스타일이 지정된 HTML 페이지를 공유할 준비가 되었습니다.
- **JSON** — 프로그래밍 방식으로 사용하기 위한 구조화된 데이터
- **클립보드에 복사** — 어디에나 빠르게 붙여넣기

### 내보내기의 진단 정보

내보낸 파일에는 디버깅 및 작업 흐름 재현을 위한 메타데이터가 자동으로 포함됩니다.

| Info | Description |
|------|------|
| **Agent Identity** | Name, model, and description of the agent that generated the response |
| **Tool Call Details** | Argument summary, execution duration, and success/failure status for each tool invocation |
| **Token Usage** | Total tokens consumed and cost estimate for the conversation |
| **Tool Usage Stats** | Call count and total duration per tool |

<Note>
도구 인수(API 키, 비밀번호, 토큰 등)의 민감한 정보는 안전한 공유를 위해 자동으로 `***`로 수정됩니다.
</Note>

### 대화 인쇄

마우스 오른쪽 버튼 클릭 메뉴에는 현재 대화를 PDF로 인쇄하거나 저장할 수 있는 "인쇄" 옵션도 제공됩니다. 숨겨진 iframe을 사용하여 팝업 차단기를 우회하여 브라우저의 기본 인쇄 대화 상자를 호출합니다.

### 대화 공유

마우스 오른쪽 버튼 클릭 메뉴 → "공유"를 통해 대화에 대한 **읽기 전용 공개 링크**를 생성하세요.

- **시간 제한**: 링크는 1~30일 후에 만료됩니다(구성 가능).
- **비밀번호로 보호됨**: 민감한 대화를 위한 선택적 비밀번호 게이트
- **취소 가능**: 원클릭 취소로 링크가 즉시 무효화됩니다.
- **보안**: HMAC-SHA256 서명된 URL, 엄격한 CSP 헤더, 스크립트 없음, X-Frame-Options DENY, 속도 제한(30req/min)
- **다양한 렌더링**: 구문 강조 코드 블록, 테이블 및 다크 모드 지원을 갖춘 서버측 마크다운 렌더링
- **에이전트 신원**: 대화에 사용된 에이전트 이름과 모델을 표시합니다.
- **자체 호스팅**: 모든 데이터는 서버에 유지됩니다. GitHub, Pastebin 또는 타사 서비스에 의존하지 않습니다.

로컬/데스크톱 모드에서는 대체 메시지가 사용자에게 대신 HTML을 내보내도록 안내합니다(localhost URL은 외부에서 연결할 수 없음).

## 프로젝트 폴더

색상 라벨을 사용하여 대화를 명명된 프로젝트로 구성합니다.

- 상황에 맞는 메뉴를 통해 프로젝트 간 대화 이동
- 사이드바를 필터링하여 특정 프로젝트의 대화만 표시
- 프로젝트 할당은 세션 전반에 걸쳐 지속됩니다.

## 휴지통 및 복구

실수로 대화를 삭제했나요? **세션 휴지통**은 다음을 제공합니다.

- 일시 삭제된 대화는 복구를 위해 보관됩니다.
- 원클릭 복원으로 삭제된 세션을 다시 불러올 수 있습니다.
- 확실할 경우 영구 삭제

## 소스 필터링

웹 UI, Telegram, Discord, WeChat 및 기타 35개 이상의 플랫폼 등 원본 채널을 기준으로 대화를 필터링하세요.

## 무한 스크롤

## 메시지 수정 및 재전송

이전 메시지를 편집하여 다른 문구로 다시 시도하세요. MyrmAgent는 편집하고 다시 보낼 때 완전한 프런트엔드 및 백엔드 일관성을 보장합니다.

1. **원자성 잘림** — 편집된 메시지 이후의 메시지는 새 메시지가 전송되기 _전에_ 데이터베이스에서 제거되므로 에이전트는 오래된 컨텍스트를 볼 수 없습니다.
2. **버전 보존** — 재생성된 응답은 형제 버전(`is_active` 플래그)으로 저장됩니다. 보조 메시지에서 왼쪽/오른쪽 화살표를 사용하여 버전 간 전환
3. **스마트 재생** — 4가지 사전 설정 모드(다시 시도, 더 간결함, 더 상세함, 더 창의적) 및 맞춤형 지침. 명령은 에이전트의 컨텍스트에 `[Regeneration guidance: ...]`로 주입되어 새로운 응답을 직접 조종합니다.
4. **불만 제기 자동 에스컬레이션** — 사용자 지정 지침 없이 _없이_(일반 재시도) 재생성하면 시스템은 이를 암묵적인 불만으로 해석하고 더 높은 품질의 응답을 위해 자동으로 모델 계층(SIMPLE→STANDARD→REASONING)을 업그레이드합니다. 수동 모델 전환이 필요하지 않습니다.
5. **마지막 차례 실행 취소** — 한 번의 클릭으로 마지막 사용자 + 보조 메시지 쌍이 제거되고 대화 상태가 업데이트됩니다.
4. **대화 분기** — 원본 스레드를 잃지 않고 대체 경로를 탐색하기 위해 메시지에서 분기합니다. 세 가지 진입점: 사이드바 오른쪽 클릭 메뉴, `/fork` 슬래시 명령, 모바일 작업 시트. 최신 메시지에서 즉시 분기하려면 `message_index=-1`을 사용하세요. 컨텍스트 사용량이 75%를 초과하면 빠른 주제 분기를 위해 컨텍스트 사용량 패널에 "새 주제 포크" 버튼이 나타납니다. 상위 대화에 활성 샌드박스(git worktree)가 있는 경우 분기된 하위 항목은 자동으로 원래 저장소 루트로 재설정되므로 동일한 샌드박스 작업 공간을 공유하는 여러 대화에서 파일 충돌이 방지됩니다.

<Tip>
로컬에서만 잘라내는 많은 경쟁업체와 달리 MyrmAgent의 백엔드 우선 접근 방식은 "유령 메시지"가 에이전트 컨텍스트를 오염시키는 것을 방지합니다. 모든 편집은 깨끗한 상태입니다.
</Tip>

## 미드 스트림 리디렉션(사용 중 입력)

에이전트가 적극적으로 응답을 생성하는 동안 Enter 키를 누르면 수정 사항이 **리디렉션**으로 전송됩니다. 즉, 완료를 기다리지 않고 즉시 현재 생성을 중단합니다.

| Mode | Behavior | When to use |
|------|----------|-------------|
| **Redirect** (default) | Interrupts mid-generation, preserves partial output in context, starts fresh turn with your correction | Agent is going in the wrong direction |
| **Steer** | Waits for current generation/tool to finish, then injects your message for the next turn | Agent is doing something useful but needs a course correction afterward |
| **Queue** | Adds your message to a queue, sent automatically after the current task completes | You want to line up follow-up work without interrupting |

리디렉션 모드의 주요 이점:
- **폐기된 토큰 제로** — 방향이 잘못되었음을 깨닫는 순간 생성을 중지합니다(리디렉션당 200~1,800개의 토큰 저장).
- **컨텍스트 일관성** — 부분 AI 출력은 AIMessage로 보존되므로 LLM은 사용자가 본 것과 동일한 컨텍스트를 볼 수 있습니다.
- **신속한 캐시 친화적** — 보존된 부분 텍스트는 메시지 접두사를 유지하여 다음 호출 시 캐시 적중률을 향상시킵니다.
- **학습 곡선 제로** — 기본 Enter 동작, 특수 키 조합이 필요하지 않음

**설정 → 상담원 → 통화중 입력 모드**(`redirect` / `steer` / `queue`)에서 기본 모드를 변경하세요.

## 경쟁업체 접근 방식 비교

대부분의 경쟁업체(예: Hermes 에이전트)는 사이드바 기능을 복제하는 별도의 `/history` 페이지를 사용합니다. MyrmAgent는 ChatGPT, Claude 및 Gemini(**사이드바 통합 기록**)와 동일한 패턴을 따르며 별도 페이지 접근 방식에는 없는 16가지 추가 기능을 제공합니다.

<Tip>
사이드바 접근 방식은 작업 흐름을 중단 없이 유지합니다. 기록을 검색, 내보내기, 관리하기 위해 현재 대화를 종료할 필요가 없습니다.
</Tip>
