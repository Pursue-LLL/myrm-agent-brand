# 대화형 양식(`structured_clarify`)

Myrm은 **채팅 내에서 구조화된 양식을 렌더링**합니다. 에이전트가 `structured_clarify` 도구(`ask_question_tool` 스키마)를 호출하면 WebUI가 대화에 옵션 버튼, 체크박스, 자유 텍스트 입력란을 렌더링하고, 사용자가 제출하면 동일한 run이 그 답변으로 다시 이어서 실행됩니다.

## 도구 활성화

1. 채팅에서 **Agent 설정**을 엽니다.
2. **대화형 UI**(`structured_clarify`)를 켭니다.

꺼져 있으면 Turn1에 `ask_question_tool` 스키마가 전송되지 않으므로 사용하지 않는 기능에 토큰을 지불하지 않습니다.

## 만들 수 있는 것

| 필드 | 용도 |
|------|------|
| `title` | 전체 양식의 선택적 제목 |
| `questions[]` | 하나 이상의 질문을 하나의 양식으로 렌더링 |
| `questions[].options[]` | 선택 버튼(`id` + `label` + 선택적 `description`) |
| `questions[].allow_multiple` | 단일 선택 대신 체크박스로 렌더링 |
| `questions[].options`(비움) | 자유 텍스트 입력란 렌더링 — 옵션을 생략하면 직접 입력 |
| `requires_confirmation` | 되돌릴 수 없거나 고위험 작업 전 사용자 명시적 승인 요구 |
| `context` | 질문 위에 표시되는 배경 설명 |

## 왕복 동작 방식

1. 에이전트가 `structured_clarify`를 호출하면 run이 대기 상태가 됩니다.
2. WebUI가 채팅에 양식을 렌더링하며, **채팅 스트림을 차단하지 않습니다**.
3. 사용자가 제출하면 답변이 저장되고 동일한 run이 해당 답변으로 **자동 재개**됩니다.
4. 백엔드에 **900초** 타임아웃 가드가 등록되어, 사용자가 끝내 답하지 않으면 `no_answer`로 자동 재개됩니다. 잊힌 양식이 세션을 영구히 막지 않습니다.

Harness의 **`ClarificationGuardMiddleware`**가 턴당 최대 하나의 `ask_question_tool` 호출만 허용하고 병렬 도구를 차단하여 양식과 도구 계획의 일관성을 유지합니다.

## 사용 시점

`structured_clarify`는 **명확화 질문과 명시적 승인**에 사용합니다 — 배포 체크리스트, 파괴적 작업 확인, 분기 선택 등입니다. 대시보드, 차트, 장기 실행 패널에는 **Mermaid 아티팩트**나 아티팩트 파일을 사용하십시오. 양식은 '묻기' 위한 것이지 '데이터 표시'를 위한 것이 아닙니다.

## 대용량 파일 인라인 보호

HTML/SVG/Mermaid 아티팩트는 기본적으로 채팅 스트림에서 자동 확장 렌더링됩니다. 아티팩트가 **1 MB**(`LARGE_FILE_THRESHOLD`)를 초과하면 인라인 렌더러가 우아하게 저하됩니다.

1. 콘텐츠 fetch도 `srcDoc` 렌더링도 발생하지 않습니다(OOM / 브라우저 지연 방지).
2. 파일 크기와 **"전체 화면 보기"** 버튼을 보여주는 간결한 폴백 카드가 표시됩니다.
3. 클릭하면 `ArtifactPortal`이 격리 URL 모드(`iframe src`)로 내용을 로드합니다 — 파일 크기와 무관하게 성능 위험이 없습니다.

이를 통해 인라인 미리보기가 멈추거나 비어 있어 대용량 생성 파일(데이터 대시보드, 복잡한 SVG 인포그래픽)을 "실패한 작업"으로 오해하는 것을 방지합니다.

| 제품 | 대용량 파일 보호 |
|------|-----------------|
| **Myrm** | 1 MB 임계값 + 폴백 CTA + URL 모드 안전 렌더 + 프리로드 생략 |
| Hermes | 데스크톱만(512 KB), WebUI 보호 없음 |
| LobsterAI / OpenClaw | 보호 없음, 직접 srcDoc 렌더 |
