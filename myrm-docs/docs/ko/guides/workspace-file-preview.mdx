# 작업 공간 파일 미리보기

작업 공간 파일 브라우저는 에이전트 샌드박스의 파일을 보여줍니다. 파일을 클릭하면 Myrm이 표시 방식을 결정합니다 — **텍스트는 텍스트로, 리치 미디어는 작업 공간을 벗어나지 않고 앱 안에서 미리보기**.

## 앱 내 미리보기 유형

| 파일 유형 | 동작 |
|-----------|------|
| PDF | react-pdf 인라인 렌더링, 스크롤 및 확대 가능 |
| 이미지(PNG/JPEG/WebP/…) | 앱 내 전체 크기 렌더링 |
| 비디오 / 오디오 | 스트리밍 URL 기반 앱 내 플레이어 |
| SVG | 인라인 벡터 렌더링 |
| Markdown / 코드 / 일반 텍스트 | 기존 텍스트 뷰어 및 편집 화면 |
| 알 수 없거나 지원되지 않는 바이너리 | 다운로드 폴백 — 깨진 텍스트 금지 |

## 스마트 텍스트/바이너리 판정

Myrm은 추측하지 않습니다. 백엔드는 스캔 중에 제로 I/O 확장자 감지로 각 파일에 권위 있는 `is_text` 플래그를 표시하고, 프론트엔드는 이 플래그에 따라 라우팅합니다:

- **텍스트 파일**은 크기 제한과 함께 제공되어 거대한 로그가 페이지를 멈추지 않습니다.
- **바이너리 파일**은 HTTP Range로 전체 스트리밍 — 잘린 조각이 아닌 완전한 PDF, 미리보기와 다운로드 모두 온전합니다.

알 수 없는 확장자도 안전합니다. 백엔드가 텍스트로 분류하지 못하면 바이너리로 처리되어 다운로드를 제공하며, 깨진 텍스트로 렌더링하지 않습니다.

## 안전한 다운로드

다운로드 응답은 헤더 주입을 차단(CR/LF 제거)하고 비 ASCII 파일명을 RFC 5987로 인코딩합니다 — 중국어, 한국어, 이모지 파일명도 어떤 플랫폼에서든 정확히 다운로드됩니다.

## 미리보기 엔진

아티팩트 렌더러는 채팅과 작업 공간 브라우저에서 재사용됩니다: PDF, 문서, 스프레드시트, 이미지, 비디오, 오디오, SVG, 인터랙티브 UI 미리보기가 하나의 렌더링 파이프라인을 공유합니다. 작업 공간 경로는 여기에 바이너리 스트리밍과 안전한 헤더 동작을 더합니다.
