# 에이전트 템플릿

일반적인 워크플로우를 위해 사전 구성된 템플릿으로 시작하세요. 템플릿은 사전 설정된 모델 선택, 도구, 시스템 프롬프트, 기술 세트 및 성격 구성을 제공합니다.

## 템플릿 사용

1. **에이전트 > 새 에이전트**로 이동합니다.
2. 갤러리에서 템플릿을 선택하세요
3. 필요에 따라 매개변수를 사용자 정의합니다(모델, 도구, 권한)
4. 에이전트를 저장하고 사용을 시작하세요

## 템플릿 마켓

템플릿 마켓은 팀 협업 및 수직 도메인 전문 지식을 다루는 즉시 사용 가능한 9가지 템플릿을 제공합니다. 템플릿을 클릭하면 올바른 기술, 프롬프트 및 아바타를 갖춘 완전히 구성된 에이전트가 즉시 생성됩니다.

### 내장 사전 설정

일반적인 사용 사례를 다루는 27개의 기본 제공 에이전트: 일반 보조자, 콘텐츠 작성자, 연구 분석가, 코드 개발자, 번역가, SEO 전략가, 소셜 인텔리전스 등.

## 에이전트 마켓플레이스(기업)

팀과 조직의 경우 **에이전트 마켓플레이스**를 통해 구성원은 조직 전체에 에이전트 구성을 게시, 검색 및 설치할 수 있으며 개인 전문 지식을 공유 조직 자산으로 전환할 수 있습니다.

### 에이전트 게시

조직 마켓플레이스에 에이전트를 게시하는 경우:

- **종속성 번들링** — 에이전트가 참조하는 스킬, MCP 도구 및 하위 에이전트가 자동으로 패키지에 번들됩니다.
- **자격 증명 제거** — 민감한 필드의 7개 카테고리(`api_key`, `auth_token`, `secret`, `password`, `token`, `credentials`, `private_key`)는 게시 전에 반복적으로 제거됩니다.
- **자동 버전 관리** — 게시할 때마다 버전 번호가 증가합니다. 이전 버전은 계속 액세스 가능

### 마켓플레이스에서 설치

1. **에이전트 > 마켓플레이스**에서 조직 마켓플레이스를 찾아보세요.
2. 에이전트를 선택하고 **설치**를 클릭합니다.
3. 자동 ID 재매핑(UUID 충돌 없음) 및 종속성 중복 제거를 통해 에이전트 프로필이 샌드박스에 푸시됩니다.
4. 자신만의 API 키를 구성하고 에이전트 사용을 시작하세요.

### 마켓플레이스 기능

| Feature | Description |
|---------|-------------|
| **Org-scoped isolation** | Only org members can browse, publish, or install — external users are denied |
| **Install count & popularity** | Each install increments a counter; popular agents surface to the top |
| **Search & filter** | Search by name or description to find the right agent |
| **Version management** | Retrieve the latest or any specific version of a published agent |
| **Archive** | Publishers can archive their own entries; org admins can archive any entry |
| **RBAC** | Publishing requires org membership; archiving respects publisher ownership and admin privileges |
| **Force-push updates** | Org admins can push the latest version to all installed sandboxes — active sandboxes receive the update immediately via Control Plane HTTP import; inactive sandboxes are skipped until they are active again. Before overwriting, the server auto-snapshots the current profile so users can roll back with one click. The push button is only visible to org admins |
| **Batch status query** | Listing marketplace entries shows install status for all entries in a single optimized query (no N+1 performance issues) |

<Tip>
새로운 팀 구성원은 처음부터 구축하는 대신 마켓플레이스에서 입증된 에이전트 구성을 설치하여 몇 분 만에 생산성을 높일 수 있습니다.
</Tip>

#### 안전한 업그레이드 및 원클릭 롤백

Force-push 업데이트는 로컬에서 커스터마이징한 내용을 절대 깨지 않도록 설계되었습니다.

- **빈 필드로 덮어쓰지 않음** — 패키지에서 빈 값으로 직렬화된 필드는 '변경 없음'으로 처리되어 로컬 설정(메모리 정책, 워크스페이스 정책, 도구 바인딩)이 업그레이드 후 그대로 유지됩니다.
- **로컬 스킬/서브 에이전트 바인딩 유지** — 설치 시 publisher 측 ID가 로컬 저장소로 재매핑되었으며 force-push는 이를 절대 publisher 측 ID로 덮어쓰지 않습니다.
- **모든 푸시 전 자동 스냅샷** — 각 업데이트는 `pre-force-push` 스냅샷을 먼저 작성하고 `AGENT_CONFIG_UPDATED` 이벤트를 발행합니다. 새 버전이 이상하게 동작하면 업그레이드 전 정확한 구성으로 원클릭 롤백합니다.
- **보안 채널** — 제어 평면은 모든 푸시를 인증합니다(token + 패키지 서명). 토큰 누락/오류는 `403`으로 거부되고, 존재하지 않는 대상으로 푸시하면 `404`(fail-closed)를 반환합니다.

## 내보내기, 가져오기 및 복제

인스턴스 간에 에이전트 구성을 공유하거나 백업하세요.

### 내보내다

**에이전트 설정 > 내보내기**에서 에이전트를 JSON 파일로 내보냅니다. 내보내기에서는 자격 증명 유출을 방지하기 위해 중요한 인증 필드(`api_key`, `auth_token`, `secret`, `password`, `token`)를 자동으로 제거합니다. 팀 에이전트는 반복적으로 내보내지며 모든 SubAgent 구성이 포함됩니다.

### 가져오기

**에이전트 설정 > 가져오기**를 통해 이전에 내보낸 에이전트 JSON을 가져옵니다. 가져온 에이전트는 항상 사용자 에이전트(`is_built_in=false`)로 생성되어 시스템 에이전트의 악의적인 삽입을 방지합니다.

### 클론

원클릭 복제는 모든 에이전트 구성의 정확한 복사본을 생성합니다. 복제본은 모든 설정(프롬프트, 도구, 기술, 모델 선택, 성격)을 유지하면서 새로운 UUID 및 이름 접미사를 받습니다.

### 프로필 타임머신

구성이 변경될 때마다 자동 스냅샷이 생성됩니다. **에이전트 설정 > 스냅샷**으로 이동하여 최대 10개의 기록 버전을 찾아보고 클릭 한 번으로 롤백할 수 있습니다. 이는 업계 독점 기능입니다.

## 사용자 정의 템플릿 만들기

구성된 에이전트를 재사용 가능한 템플릿으로 저장합니다.

1. 원하는 설정으로 에이전트를 구성합니다.
2. **에이전트 설정 > 템플릿으로 저장**으로 이동합니다.
3. 이름, 설명, 카테고리를 추가하세요.
4. 작업 공간 갤러리에서 템플릿을 사용할 수 있게 됩니다.

## 파이프라인 템플릿

복잡한 다단계 워크플로의 경우 **파이프라인 템플릿**(PipelineWizard 제공)을 사용하세요.

- Skill 파일에서 YAML 머리말로 정의됨
- 탐색 질문, 역할 템플릿, 작업 그래프 시드 포함
- 템플릿에서 연결된 Kanban 작업 DAG 생성

파이프라인 워크플로에 대한 자세한 내용은 [칸반 및 오케스트레이션](/docs/core-concepts/kanban-orchestration)을 참조하세요.
