# 테마 스튜디오

Myrm의 Theme Studio를 사용하면 4단계 편집기, 17가지 내장 사전 설정, AI 생성 기술 및 커뮤니티 마켓플레이스를 통해 배경화면, 색상 팔레트, 글꼴, 레이아웃 등 전체 작업 공간 모양을 사용자 정의할 수 있습니다.

## 경로 인식 가독성

Myrm은 페이지를 **몰입형**(채팅) 장면과 **기능적**(칸반, 설정, 브레인 등) 장면으로 자동 분류합니다. 기능적 페이지는 탐색 0.92, 사이드바 0.90, 기본 콘텐츠 0.94, 카드 0.96 등 더 높은 표면 불투명도를 적용하여 생생한 배경화면에서도 텍스트를 읽을 수 있게 유지합니다.

레이아웃(미적 선택)과 장면(경로 기반 가독성)은 직교합니다. 페이지 전환은 구성이 필요 없는 자동입니다.

## 제로 플래시 지속성

테마는 3계층 메커니즘을 통해 새로 고침, 새 창, 다시 시작 시에도 유지됩니다.

1. **Pre-init 스크립트** — 차단 `beforeInteractive` 스크립트는 React가 수화되기 전에 `localStorage`에서 테마 토큰을 복원하여 기본 테마의 플래시를 제거합니다.
2. **ThemeProfileProvider** — 루트 레이아웃 수준 React 컨텍스트는 활성 프로필을 컴파일하고 CSS 변수를 실시간으로 동기화합니다.
3. **ConfigSync** — 테마 프로필 메타데이터가 서버에 동기화되므로 장치를 전환하면 테마가 자동으로 복원됩니다(배경화면 자산은 새 장치에서 `.myrmtheme` 다시 가져오기를 사용합니다).

## 휴대용 `.myrmtheme` 패키지

창작물을 `.myrmtheme` 파일로 내보냅니다. `recipe.json` 매니페스트, 히어로 이미지, 미리보기 썸네일 및 미디어 자산이 포함된 보안 ZIP 번들입니다. 서버는 zip 폭탄 감지, 경로 탐색 방지, MIME 화이트리스트 및 애니메이션 WebP 거부를 통해 모든 패키지의 유효성을 검사합니다.

Tauri 데스크탑(Windows, macOS, Linux)에서 `.myrmtheme` 파일을 두 번 클릭하면 가져오기 미리보기가 직접 열립니다.

## AI 테마 생성

내장된 `generate-myrm-theme` 기술은 자연어 프롬프트에서 구조화된 레시피 JSON을 생성합니다. 미리보기 및 원클릭 적용을 위해 출력이 Theme Studio에 직접 공급되며 원시 CSS 또는 JavaScript가 삽입되지 않습니다.

## 아티팩트 테마 동기화

AI 생성 HTML 위젯(아티팩트) 및 MCP 앱 iframe은 위젯 테마 브리지를 통해 호스트 작업공간 테마를 자동으로 상속합니다. 22개의 CSS 변수는 70개 이상의 Tailwind와 유사한 유틸리티 클래스와 미리 스타일이 지정된 양식 요소가 포함된 시맨틱 위젯 토큰에 매핑됩니다.

데스크 펫 희귀 발광 및 상태 풍선은 동일한 호스트 구독을 사용합니다. Theme Studio 실시간 미리 보기에서 색상을 조정하거나 사전 설정을 전환하면 페이지를 다시 로드하지 않고도 위젯과 컴패니언 악센트가 동기화된 상태로 유지됩니다.

## 3개 배포 일관성

| Deployment | Theme Capabilities |
|---|---|
| **Cloud sandbox** | Full marketplace + ConfigSync + Gallery |
| **Local Web UI** | Full Theme Studio + `.myrmtheme` import + all presets |
| **Tauri Desktop** | All of the above + `.myrmtheme` file association + multi-window sync |

## 빠른 시작

1. **설정 → 테마 스튜디오**(또는 설정의 모양 탭)를 엽니다.
2. 내장된 사전 설정을 선택하거나 처음부터 시작하세요.
3. 배경화면을 업로드하고 강조 색상을 조정한 후 레이아웃을 선택하세요.
4. **적용**을 눌러 지속하거나 **내보내기**를 눌러 `.myrmtheme` 패키지를 저장하세요.
5. **갤러리** 탭에서 커뮤니티 테마를 찾아보거나 **제작자 센터**를 통해 자신만의 테마를 제출하세요.
