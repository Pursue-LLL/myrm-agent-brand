# 작업 단위 및 비용 관리

Myrm은(는) SaaS 작업 단위 청구부터 로컬 BYOK 예산 통제 및 전체 체인 분석 대시보드에 이르기까지 모든 배포 모드에 걸쳐 포괄적인 비용 관리 시스템을 제공합니다.

## 작업 단위(SaaS)

Work Unit은 모든 SaaS 플랫폼 사용에 대한 통합 통화입니다.

### WU를 소비하는 것

| Activity | Rate |
|----------|------|
| LLM input tokens | Varies by model |
| LLM output tokens | Varies by model |
| Tool execution | Per invocation |
| Sandbox active time | Per minute |
| File storage | Per GB/month |

### 계획

| Plan | WU/month | Price | Extras |
|------|----------|-------|--------|
| Free | 600 | $0 | +50/day refresh |
| Companion | 6,000 | $19/mo | Unlimited agents |
| Pro | 18,000 | $49/mo | 7-day free trial |
| Max | 60,000 | $149/mo | Dedicated support |

## 토큰 효율성

Myrm의 최적화된 시스템 프롬프트는 유사한 플랫폼의 15,000개 이상의 토큰과 비교하여 ~1,765개의 토큰만 사용합니다. 즉각적인 캐싱을 통해 유효 비용이 최대 97%까지 절감됩니다.

## 로컬/데스크탑

로컬 WebUI 및 Tauri 데스크톱 모드는 WU를 사용하지 않습니다. BYOK(직접 키 가져오기)을 통해 LLM 제공자에게 직접 비용을 지불합니다.

## 예산 통제

Myrm에는 예상치 못한 비용으로부터 귀하를 보호하는 3차원 예산 시스템이 포함되어 있습니다.

### 3차원

| Dimension | What it limits | Example |
|-----------|---------------|---------|
| Per-session | Single conversation cost | $2.00 per chat |
| Daily | Total daily spend | $10.00/day across all chats |
| Per-call | Individual LLM call cost | $0.50 per API call |

### 4가지 프로그레시브 레벨

1. **확인** — 정상 작동
2. **경고** — 한도에 가까워짐, 토스트 알림이 표시됨
3. **마무리** — 에이전트가 현재 작업을 마무리하고 도구 호출이 제한됩니다.
4. **초과** — 강제 중지, 재설정될 때까지 새 메시지가 차단됨

**설정 > 시스템 > 예산 정책**에서 모든 예산을 구성하세요. 시스템은 프롬프트 캐시를 존중합니다. 예산 집행은 캐시 접두어 안정성을 유지하는 프롬프트 삽입을 사용합니다.

## 기업 조직 예산(클라우드 전용)

클라우드 호스팅 계획을 사용하는 조직의 경우 관리자는 자동 임계값 경고를 통해 팀 수준의 월별 WU 예산을 설정할 수 있습니다.

### 작동 방식

1. 관리자는 월별 WU 예산 및 경고 임계값을 설정합니다(예: 80%에서 10,000WU).
2. 시스템은 모든 팀 구성원의 WU 소비를 실시간으로 추적합니다.
3. 총 조직 사용량이 임계값을 초과하면 자동으로 경고가 전송됩니다.
4. 경고는 매월 멱등성을 갖습니다. 경고 폭풍이 발생하지 않습니다.
5. 임계값을 변경하면 경고 표시가 재설정되므로 새 임계값이 즉시 적용됩니다.

### 사용 요약 API

`/api/enterprise/org/{org_id}/usage-summary` 엔드포인트는 자세한 분석을 반환합니다.

- **구성원별 사용량** — 이번 달 각 팀 구성원이 소비한 금액
- **카테고리별 사용량** — LLM 출력, 도구 실행 등
- **사용 비율** — 현재 소비량 대비 월예산
- **예산 상태** — 임계값 초과 여부

이는 클라우드 호스팅 엔터프라이즈 배포를 위한 제어 영역에서만 사용할 수 있습니다.

## 비용 분석 대시보드

**설정 > 시스템 > 사용 통계**를 통해 액세스하여 포괄적인 비용 분석을 확인하세요.

### 볼 수 있는 것

- **글로벌 개요** — 총 통화 수, 토큰(7종), 비용, 캐시 적중률
- **일일 추세** — 토큰 사용량 및 비용에 대한 7일 또는 30일 시계열
- **모델별 분석** — 사용된 각 모델의 호출, 토큰 및 비용
- **라우팅 분석** — 스마트 라우팅이 작업을 여러 계층에 분산하는 방법(단순/표준/추론)
- **예상 절감액** — 스마트 라우팅이 없었다면 지불했을 금액과 실제 비용
- **캐시 절약** — 프롬프트 캐싱과 캐시 중단 진단을 통해 절약된 금액
- **활동 히트맵** — 일주일 중 가장 활동적인 시기
- **상위 세션** — 가장 비용이 많이 드는 대화 순위
- **세션별 드릴다운** — 자세한 토큰/도구/타임라인 분석을 보려면 세션을 클릭하세요.

### 메시지당 비용

모든 보조 메시지에는 캐시 절약 비율을 포함하여 해당 특정 응답의 실시간 비용을 표시하는 **WaterDrop** 아이콘이 표시됩니다. **설정 > 개인 > 예상 비용 표시**에서 활성화하세요.

### 컨텍스트 사용 링

메시지 입력 옆에 있는 원형 표시기는 모델의 컨텍스트 창이 현재 사용되는 정도를 보여줍니다. 사용량이 증가함에 따라 색상이 변경됩니다.
- **녹색** — 건강함(<75%)
- **황색** — 한계에 근접함(75-90%)
- **빨간색** — 심각(>90%)
