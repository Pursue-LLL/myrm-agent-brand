# 빠른 시작

선호하는 배포 방식을 고르고 바로 시작하세요.

<Note>
**다른 에이전트에서 옮기시나요?** 먼저 [경쟁사 비교](/ko/getting-started/competitor-comparison)를 확인하세요. Hermes, OpenClaw 등과 Myrm의 기능·마이그레이션 경로를 한 페이지에서 비교합니다. Myrm은 **SaaS**, **자체 호스팅 WebUI**, **데스크톱** 중에서 선택할 수 있습니다. 스킬과 메모리는 GUI 마이그레이션 마법사(데스크톱·로컬 WebUI)로 이전할 수 있습니다.
</Note>

## SaaS 클라우드(가장 빠름)

설치 없이 [app.myrmagent.ai](https://app.myrmagent.ai/auth/login)에서 계정을 만드세요.

## 로컬 배포(Docker)

<Steps>
  <Step title="저장소 클론">
    ```bash
    git clone https://github.com/Pursue-LLL/myrm-agent.git
    cd myrm
    ```
  </Step>
  <Step title="서비스 시작">
    ```bash
    docker compose up -d
    ```
  </Step>
  <Step title="UI 열기">
    브라우저에서 [http://localhost:3000](http://localhost:3000)을 여세요.
  </Step>
</Steps>

## 데스크톱 앱(Tauri)

[GitHub Releases](https://github.com/Pursue-LLL/myrm-agent/releases)에서 사용 중인 OS용 최신 빌드를 받으세요.

| 플랫폼 | 형식 |
|--------|------|
| macOS(Apple Silicon) | `.dmg` |
| macOS(Intel) | `.dmg` |
| Windows | `.msi` |
| Linux | `.AppImage` |

## 다음 단계

설치가 끝나면 다음을 진행해 보세요.

1. **첫 Agent 구성** — 모델과 도구 설정
2. **대화 시작** — 작업을 설명하고 Agent가 실행하도록 요청
3. **메모리 탐색** — 세션을 넘어 Agent가 어떻게 학습하는지 확인

<Tip>
**자동 레벨 업**: Myrm은 AI 역량 등급(L1–L5)을 추적합니다. 첫 대화, 첫 도구 사용, 첫 승인 같은 마일스톤을 달성하면 자동으로 레벨이 올라가며 고급 기능이 열립니다. 수동 설정은 필요 없습니다.
</Tip>
