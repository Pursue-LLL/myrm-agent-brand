# Myrm에 오신 것을 환영합니다

Myrm은 **오픈 코어** AI 에이전트 작업 공간입니다. WebUI, API 서버 및 Tauri 데스크톱 앱은 오픈 소스입니다. 에이전트 하네스 런타임 및 SaaS 제어 평면은 독점적입니다. 100개 이상의 LLM 모델, 28개의 메시징 채널 및 3가지 배포 모드(로컬 WebUI, Tauri 데스크톱 또는 SaaS 클라우드)를 통해 지속적인 사용자별 샌드박스, 교차 세션 메모리 및 GUI 최초 경험을 얻을 수 있습니다.

## 주요 기능

| 기능 | 설명 |
|------|------|
| **Goal 관리** | 4차원 예산·수용 기준·자율 실행이 있는 목표 정의 |
| **칸반 보드** | DAG 의존성, 우선순위 스케줄링, 좀비 탐지 |
| **서브 Agent 오케스트레이션** | Spawn/Chain/Batch/DAG/Verified/Swarm 6패턴 + 제로 트러스트 검증 |
| **컨텍스트 엔지니어링** | 5계층 압축 파이프라인, 가역 아카이브, 높은 prompt cache 적중률 |
| **28개 채널** | WeChat, Telegram, Discord, Slack, Email, SMS 등 |
| **6계층 보안** | 예산·권한·루프 탐지·PII·감사 로그 |
| **Computer Use** | macOS·Linux 네이티브 화면 제어 |
| **웹 검색·Fetch** | 7개 검색 엔진 + 3단 로컬 fetch |
| **음성 상호작용** | 5 TTS + 5 STT 엔진 |
| **아티팩트 게시** | 16+ 미리보기 형식, 정적 번들 호스팅, 1~30일 취소 가능한 공유 링크(선택적 비밀번호 게이트, 원클릭 취소 → 즉시 404) |

## 배포 옵션

| 모드 | 설명 | 비용 |
|------|------|------|
| **로컬 WebUI** | 브라우저 기반 자체 호스팅 | 무료(BYOK) |
| **Tauri 데스크톱** | 임베디드 백엔드 네이티브 앱 | 무료(BYOK) |
| **SaaS 클라우드** | WU 과금 관리형 인프라 | 무료 티어 + 유료 |

세 모드는 동일 코드베이스·기능 세트를 공유하며, 데이터와 설정을 옮길 수 있습니다.

## 토큰 효율성

Myrm의 최적화된 시스템 프롬프트는 **~1,765개의 토큰**만 사용합니다. 이는 동급 플랫폼보다 86% 적은 수치입니다. 즉각적인 캐싱을 통해 유효 비용이 최대 **97%**까지 절감됩니다.

## 개방형 대 하네스

**WebUI 및 API 서버**는 오픈 소스입니다. **에이전트 하네스**(도구, 메모리 엔진, 브라우저 풀)는 샌드박스 내부의 프로덕션 런타임으로 제공됩니다. 전체 구조는 [제품 아키텍처](/ko/getting-started/product-architecture)를 참고하세요.
