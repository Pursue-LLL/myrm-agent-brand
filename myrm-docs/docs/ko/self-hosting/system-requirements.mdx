# 시스템 요구사항

## 최소

| Resource | Requirement |
|----------|------------|
| CPU | 2 cores |
| RAM | 4 GB |
| Disk | 10 GB |
| OS | Linux, macOS, or Windows (Docker) |
| Docker | 24+ with Compose v2 |

## 추천

| Resource | Requirement |
|----------|------------|
| CPU | 4+ cores |
| RAM | 8+ GB |
| Disk | 50+ GB SSD |
| Network | Stable internet for LLM API access |

## 선택적 종속성

- **Qdrant** — 고급 메모리 검색을 위한 벡터 데이터베이스(Docker Compose에 포함됨)
- **Redis** — 캐싱 및 속도 제한용(선택 사항)

## 배포 모드 한눈에 보기

동일한 코드베이스가 세 가지 모드로 실행되며, 각 모드마다 리소스 요구 사항이 다릅니다. 모델은 항상 API를 통해 접근하므로(BYOK, relay 또는 선택적 로컬 Ollama) **어떤 모드에서도 GPU가 필요하지 않습니다**.

| 모드 | 실행 위치 | 리소스 요구량 | 직접 관리할 것 |
|------|----------|--------------|---------------|
| **로컬 WebUI** | 사용자 머신 또는 NAS(Docker) | 호스트 CPU + RAM | 서버, 업그레이드, 백업 |
| **Tauri 데스크톱** | 노트북/데스크톱 네이티브 앱 | 가벼운 네이티브 셸 | 설치 후 실행만 |
| **클라우드(관리형)** | 컨트롤 플레인 샌드박스 | 플랫폼이 처리 | 없음 — 모델 API 키만 직접 준비 |

## 사용 강도별 사양 선택

대부분의 셀프 호스팅 환경은 라이트 계층에 해당합니다. 헤비 계층은 팀 사용 또는 지속적인 멀티 에이전트 워크로드에만 예약하세요.

| 계층 | 워크로드 | 권장 사양 |
|------|---------|-----------|
| **라이트** | 개인 비서, 일상 채팅, 단일 에이전트 | 2 CPU / 4 GB / 10 GB |
| **미디엄** | 코딩 및 브라우저 작업, 예약 작업 | 4 CPU / 8 GB / 50 GB |
| **헤비** | 팀 사용, 다중 에이전트, 지속적 부하 | 8 CPU / 16 GB / 100 GB+ |

## 리소스 제한(OOM 방지)

Docker Compose 스택은 저사양 호스트(NAS, 구형 PC)를 보호하기 위해 구성 가능한 리소스 제한을 제공합니다:

| 변수 | 기본값 | 의미 |
|------|--------|------|
| `MYRM_MEM_LIMIT` | `0`(제한 없음) | Myrm 컨테이너 최대 메모리, 예: `3g` |
| `MYRM_CPU_LIMIT` | `0`(제한 없음) | Myrm 컨테이너 최대 CPU, 예: `2.0` |

스택을 시작하기 전에 설정하세요:

```bash
MYRM_MEM_LIMIT=3g MYRM_CPU_LIMIT=2.0 docker compose up -d
```

NAS 또는 공유 호스트에서는 항상 `MYRM_MEM_LIMIT`을 설정하여 에이전트가 전체 머신을 다운시키지 못하게 하세요.

전체 변수 목록은 [환경 변수 참조](/docs/ko/self-hosting/environment-variables)를 참조하세요.

## 경쟁 제품과의 정직한 비교

공식 셀프 호스팅 최소 사양(브라우저 자동화는 모든 플랫폼에서 RAM 요구량을 비슷하게 높입니다):

| 플랫폼 | 최소 사양 | 비고 |
|--------|-----------|------|
| **Myrm** | 2 CPU / 4 GB / 10 GB | GPU 불필요; 모델은 API 경유; 리소스 제한 구성 가능 |
| **MonkeyCode** | 콘솔 2C/4G/40G + 개발 호스트 8C/16G/100G | 개발 호스트는 팀 규모에 따라 확장; 로컬 추론에는 GPU 필요할 수 있음 |
| **OpenClaw** | 2 vCPU / 4 GB / 20 GB+(커뮤니티 추정) | 공식 문서는 Node 런타임만 명시, 하드웨어 최소 사양 미공개; 브라우저 자동화: 4C/8G; 로컬 모델은 16 GB+ RAM 필요 |

출처: [MonkeyCode README](https://github.com/chaitin/MonkeyCode)(공식 자체 호스팅 사양) 및 [OpenClaw 문서](https://docs.openclaw.ai/install)(Node만), OpenClaw 하드웨어 사양은 커뮤니티 추정치([1](https://provision.ai/openclaw-hardware-requirements), [2](https://clawtrust.ai/blog/openclaw-server-requirements)).
