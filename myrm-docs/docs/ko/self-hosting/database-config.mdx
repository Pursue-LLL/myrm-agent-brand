# 데이터베이스 구성

Myrm은 모든 데이터를 하나의 데이터 디렉터리(`MYRM_DATA_DIR`, 기본값 `~/.myrm`)에 저장합니다. 외부 데이터베이스나 벡터 서비스는 필요하지 않습니다.

| 경로 | 내용 |
|------|------|
| `data.db` | 기본 SQLite 데이터베이스 |
| `qdrant/` | 메모리 검색에 사용하는 내장 벡터 저장소 |
| `checkpoints.db` | 에이전트 체크포인트 |
| `memory/` | 메모리 콘텐츠 |

내장 벡터 저장소가 자신의 폴더를 잠그기 때문에 하나의 데이터 디렉터리는 한 번에 하나의 Myrm만 사용할 수 있습니다. 폴더를 열지 못한 두 번째 인스턴스는 계속 실행되지만 새 메모리를 영구적으로 저장하지 않으며 앱에 경고가 표시됩니다.

## 그래프 저장소(선택)

`DATABASE_URL`은 선택적 Apache AGE(PostgreSQL) 그래프 저장소를 가리킵니다. 비워 두면 그래프는 데이터 디렉터리 안의 SQLite에 저장됩니다.

## 백업

Myrm을 종료한 뒤 데이터 디렉터리 전체를 복사하세요.

```bash
cp -R "${MYRM_DATA_DIR:-$HOME/.myrm}" "./backups/myrm-$(date +%Y%m%d)"
```
