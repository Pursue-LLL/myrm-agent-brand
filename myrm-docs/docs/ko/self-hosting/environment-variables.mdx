# 환경 변수

환경 변수를 사용하여 Myrm 인스턴스를 구성합니다. `.env.example`을 `.env`에 복사하고 사용자 정의합니다.

## LLM 제공업체(WebUI에서 설정, 환경 변수가 아님)

제공업체 자격 증명은 **환경 변수가 아닙니다**. WebUI의 **설정 > 모델 서비스**에서 추가하세요. 각 제공업체는
자체 키를 보관하며, Myrm은 해당 키를 로컬 데이터 디렉터리(`MYRM_DATA_DIR`, 기본값 `~/.myrm`)에 암호화하여
저장합니다. `.env`에는 프로세스 및 운영 설정만 담깁니다.

> 서버와 함께 배포되는 `.env.example`에 동일한 정책이 명시되어 있습니다. `.env`에는 `[P]` 프로세스 및 `[O]`
> 운영 변수만 두며, 업무 기능(LLM, 임베딩, 검색, 제공업체)은 WebUI 설정에서 관리합니다.

## 애플리케이션

| Variable | Default | Description |
|----------|---------|-------------|
| `PORT` | `3000` | HTTP server port |
| `DATABASE_URL` | (empty) | Optional Apache AGE (PostgreSQL) graph store; empty keeps the graph in SQLite under the data directory |

## Docker 작성

| Variable | Default | Description |
|----------|---------|-------------|
| `MYRM_BIND_HOST` | `127.0.0.1` | Host IP for port bindings. Set to `0.0.0.0` for LAN/remote access |
| `MYRM_PORT` | `25808` | Server API port |
| `FRONTEND_PORT` | `3000` | Frontend port |
| `MYRM_MEM_LIMIT` | `0` (unlimited) | Max memory for the Myrm container, e.g. `3g` |
| `MYRM_CPU_LIMIT` | `0` (unlimited) | Max CPUs for the Myrm container, e.g. `2.0` |
| `MYRM_WORKSPACE` | `./workspace` | Host directory mounted as the agent workspace |

## 보안

| Variable | Default | Description |
|----------|---------|-------------|
| `JWT_SECRET` | (auto-generated) | JWT signing secret |
| `ENCRYPTION_KEY` | (auto-generated) | AES-256 encryption key |

## 관측성 및 텔레메트리

| Variable | Default | Description |
|----------|---------|-------------|
| `MYRM_LOG_FORMAT` | `text` | Log format: `text` or `json` (for ELK/Loki ingestion) |
| `OTEL_EXPORTER_OTLP_ENDPOINT` | (empty) | Standard OpenTelemetry Collector endpoint (e.g. `http://localhost:4318` or `http://localhost:4317`) |
| `OTEL_EXPORTER_OTLP_PROTOCOL` | `http/protobuf` | OTLP transport protocol: `http/protobuf` or `grpc`; when unset, an endpoint on port `4317` selects `grpc` |
| `OTEL_EXPORTER_OTLP_HEADERS` | (empty) | Auth headers as `key=value,key2=value2` (e.g. `Authorization=Bearer%20<token>`); never shown in the UI |
| `OTEL_TRACES_SAMPLER` / `OTEL_TRACES_SAMPLER_ARG` | `parentbased_always_on` | Standard sampling, e.g. `parentbased_traceidratio` with `0.1` keeps 10% of traces |
| `OTEL_SDK_DISABLED` | `false` | `true` switches all trace and metric export off |
| `OTEL_TRACES_EXPORTER` / `OTEL_METRICS_EXPORTER` | `otlp` | `none` switches that one signal off. A traces-only backend rejects metric batches (Jaeger answers `404` and the server logs each failed export); set `OTEL_METRICS_EXPORTER=none` for it |
| `OTEL_INSTRUMENTATION_GENAI_CAPTURE_MESSAGE_CONTENT` | `false` | Opt-in: include prompt, reply and tool content in exported spans; off exports metadata only |
| `MYRM_LOCAL_TRACE_ONLY` | `0` | Air-gapped local mode: `1` enforces zero remote OTel export and keeps all traces purely local |
| `MYRM_CARDINALITY_FIREWALL` | `1` | Enforces metric label sanitization to prevent Prometheus high-cardinality OOM |

### 내보내기가 작동하는지 확인

설정 → 개발자 → OpenTelemetry 내보내기 카드는 구성된 값이 아니라 각 파이프라인이 실제로 전달한 결과를 보여 줍니다. 트레이스는 첫 배치가 전달되거나 거부되기 전까지 `준비됨`으로 표시되고, 이후에는 최근 결과에 따라 `활성` 또는 `전송 실패`가 됩니다. 메트릭은 별도의 상태(`꺼짐`, `준비됨`, `활성`, `전송 실패`)를 가집니다. 백엔드가 트레이스는 받고 메트릭은 거부할 수 있기 때문입니다. `GET /api/v1/system/telemetry-posture`는 동일한 실측 필드(`status`, `metrics_status`, `exported_spans`, `failed_batches`, `last_success_at`, `last_failure_at`)를 반환하며, `GET /api/v1/health/liveness`의 `gatewayRuntime` 블록에 있는 `otlp_connected`는 이 값에서 계산됩니다. 가장 최근 내보내기가 수락된 동안에만 `true`입니다.

플랫폼이 관리하는(클라우드 호스팅) 인스턴스에서는 수집기가 운영자의 것이므로 카드가 숨겨지고 API도 수집기 주소를 제공하지 않습니다.

### 요청의 트레이스가 맞물리는 방식

하나의 HTTP 요청에 대해 동일한 32자리 16진수 ID가 `X-Trace-Id` 응답 헤더, 오류 응답의 `error.trace_id`, 서버 로그 줄의 ID, 내보낸 스팬의 트레이스 ID로 모두 쓰이므로, 오류 메시지에서 가져온 ID로 해당 트레이스를 바로 찾을 수 있습니다. 유효한 `X-Trace-Id`(32자리 16진수, 모두 0은 아님) 또는 W3C `traceparent`를 보내는 호출자는 자신의 ID를 유지하며(`X-Trace-Id`가 우선), 그 밖의 값은 새 ID로 대체됩니다.

스팬은 에이전트 실행, 모델 호출, 도구 호출이며, 채팅 채널에서는 스트리밍 응답마다 하나의 `stream_reply` 트레이스가 추가됩니다. HTTP 요청 자체는 스팬을 만들지 않습니다. 헬스 프로브가 노이즈만 늘리기 때문입니다. `OTEL_*` 변수는 서버만 읽습니다. 에이전트가 실행하는 프로그램(터미널 명령, 스크립트, 백그라운드 프로세스, 브라우저)은 이를 상속하지 않으며, OpenTelemetry가 필요한 프로그램은 자체 명령줄에서 직접 설정합니다.
