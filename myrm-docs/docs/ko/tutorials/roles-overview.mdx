# 역할 및 산업

역할마다 AI 채택 패턴이 다릅니다. 이 섹션에서는 특정 직무 및 산업에 대한 맞춤형 지침을 제공합니다. 플레이북이 활발히 개발되고 있습니다.

## 출시 예정

- **마케팅 및 콘텐츠** — 캠페인 계획, 콘텐츠 달력, 경쟁사 추적, 소셜 미디어 자동화
- **영업 및 고객 서비스** — 리드 연구, 제안 초안, CRM 통합, 고객 응답 템플릿
- **인사 및 관리** — 채용 심사, 온보딩 체크리스트, 정책 문서 생성
- **엔지니어링 및 데이터** — 코드 검토 지원, 데이터 파이프라인 모니터링, 문서 생성
- **재무 및 분석** — 보고서 자동화, 데이터 추출, 투자 연구 요약

## 성숙도 모델

Myrm을(를) 채택하면 사용량이 자연스럽게 다음 네 가지 수준으로 진행됩니다.

| Level | Stage | Example |
|-------|-------|---------|
| **L1** | Single-task assistance | "Help me write this email" |
| **L2** | Template workflows | Reusable Skills for recurring tasks |
| **L3** | Automated pipelines | Scheduled tasks with channel delivery |
| **L4** | Team capability | Shared agents, marketplace Skills, multi-agent orchestration |

당신이 있는 곳에서 시작하세요. 이 섹션의 각 튜토리얼에서는 해당 튜토리얼이 다루는 성숙도 수준에 대해 설명합니다.
