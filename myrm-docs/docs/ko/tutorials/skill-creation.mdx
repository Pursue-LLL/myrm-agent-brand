# 스킬창작

## 시나리오

경쟁사 분석 보고서 생성과 같은 복잡한 작업을 완료했습니다. 형식과 데이터 소스를 올바르게 얻으려면 몇 번의 반복이 필요했습니다. 이제 이 워크플로를 저장하여 귀하(또는 귀하의 팀)가 모든 것을 다시 설명하지 않고 단일 명령으로 다시 실행할 수 있도록 하려고 합니다.

## 재료

- 상담원이 만족스러운 결과를 도출한 완료된 대화
- 매개변수화해야 하는 부분(예: 경쟁사 이름, 날짜 범위)에 대한 명확성

## 단계

<Steps>
  <Step title="작업을 성공적으로 완료">
만족스러운 결과를 얻을 때까지 상담원과 협력하십시오. 대화 내용은 스킬의 원료가 됩니다.
  </Step>
  <Step title="에이전트에게 스킬 생성을 요청하세요.">
같은 대화에서 다음과 같이 말합니다.

> "이것을 스킬로 바꾸십시오. 이름을 '경쟁사 분석 보고서'로 지정하십시오. 사용자는 경쟁사 이름과 날짜 범위를 입력으로 제공해야 합니다."

에이전트는 대화를 분석하고, 워크플로 논리를 추출하고, 기술 정의를 생성합니다.
  </Step>
  <Step title="검토 및 편집">
스킬은 추출된 프롬프트, 매개변수 및 설명과 함께 **설정 → 스킬**에 나타납니다. GUI에서 모든 필드를 직접 편집할 수 있습니다.
  </Step>
  <Step title="당신의 기술을 사용하십시오">
슬래시 명령을 사용하여 대화에서 트리거하십시오.

> `/competitor-analysis-report`

아니면 스킬 패널에서 선택하세요. 에이전트는 스킬 지침을 로드하고 필요한 입력을 요청합니다.
  </Step>
</Steps>

<Note>
**스킬 진화**: 시간이 지남에 따라 에이전트는 피드백과 사용 패턴을 기반으로 스킬을 자동으로 개선할 수 있습니다. 자세한 내용은 [스킬 진화](/docs/core-concepts/skill-evolution)를 참조하세요.
</Note>

## 제공 가능

슬래시 명령이나 GUI 선택을 통해 호출할 수 있고 에이전트의 스킬 라이브러리에 저장된 재사용 가능한 스킬입니다.

## 승인 기준

- [ ] 스킬은 원래 대화와 일치하는 결과를 생성합니다.
- [ ] 입력 매개변수가 올바르게 추출되고 프롬프트됩니다.
- [ ] 스킬은 설정 → 스킬에 표시됩니다.
- [ ] 슬래시 명령이 스킬을 올바르게 활성화합니다.
