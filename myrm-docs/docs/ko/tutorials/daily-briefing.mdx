# 일일 브리핑

## 시나리오

귀하는 업계 뉴스, 경쟁업체 동향, 소셜 미디어 동향을 파악해야 하는 마케팅 관리자입니다. 매일 아침 10개의 웹사이트를 확인하는 대신, 업무를 시작하기 전에 AI가 생성한 브리핑을 전달받고 싶습니다.

## 재료

- 추적하려는 주제 또는 경쟁사 목록(예: "AI 에이전트 시장", "경쟁사 제품 출시")
- 전달 채널(이메일, WeChat, Telegram, Slack 등) - 첫 실행 시 선택 사항

## 단계

<Steps>
  <Step title="대화 시작">
새 채팅을 열고 원하는 것이 무엇인지 설명하세요.

> "AI 에이전트 제품에 대한 최신 뉴스를 웹에서 검색하고, 상위 5개 기사를 요약하고, 한 줄 요약과 소스 링크로 아침 브리핑 형식으로 작성하세요."
  </Step>
  <Step title="결과 검토">
Myrm은 내장된 웹 검색(7개 엔진, 무료)을 사용하여 관련 기사를 찾은 다음 이를 구조화된 브리핑으로 요약합니다.
  </Step>
  <Step title="요구사항을 개선하세요">
범위, 형식 또는 초점 조정:

> "Manus 및 OpenClaw에 대한 소셜 미디어 언급도 포함하세요. 상단에 '핵심 요약' 섹션을 추가하세요."
  </Step>
  <Step title="스킬로 저장(선택 사항)">
결과가 만족스러우면 상담원에게 다음과 같이 질문하세요.

> "'모닝 브리핑'이라는 스킬로 저장해 두면 재사용할 수 있어요."

에이전트는 선호하는 매개변수를 사용하여 워크플로를 재사용 가능한 스킬로 추출합니다.
  </Step>
</Steps>

## 제공 가능

업계 최고의 스토리, 경쟁업체 업데이트, 주요 시사점을 포함하는 체계적인 일일 브리핑으로 Markdown 형식으로 포맷되거나 아티팩트로 전달됩니다.

## 승인 기준

- [ ] 브리핑에는 관련성 있는 최신 뉴스가 포함됩니다(24시간 이내).
- [ ] 출처는 링크와 함께 인용됩니다.
- [ ] 형식은 스캔 가능합니다(제목 + 한 줄 요약).
- [ ] 콘텐츠가 지정한 주제와 일치합니다.

## 다음은 무엇입니까?

- **전송 자동화** → [예약 자동화](/docs/tutorials/scheduled-automation)를 참조하여 매일 아침 8시에 실행하고 원하는 채널로 푸시하세요.
- **지식 베이스 추가** → 검색 가능한 역사적 참고 자료를 위해 브리핑을 [Wiki](/docs/guides/wiki-knowledge-base)에 저장하세요.
