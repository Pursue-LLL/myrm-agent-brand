# 튜토리얼

Myrm 실습 튜토리얼에 오신 것을 환영합니다. *기능 작동 방식*을 설명하는 [가이드](/docs/guides/goal-management)와는 달리, 이 튜토리얼에서는 **AI로 실제 업무 문제를 해결하는 방법**을 구체적인 결과물과 함께 단계별로 보여줍니다.

## 읽는 방법

각 튜토리얼은 일관된 5개 요소 구조를 따릅니다.

| Element | What it covers |
|---------|---------------|
| **Scenario** | A real work situation you'll recognize |
| **Materials** | Files, data, or context you need to prepare |
| **Steps** | Click-by-click walkthrough with screenshots |
| **Deliverable** | The concrete output you'll produce |
| **Acceptance** | How to verify the result is correct |

관련된 경우 배포 차이점(로컬 WebUI / Tauri 데스크톱 / SaaS 클라우드)이 표시됩니다. 대부분의 튜토리얼은 세 가지 모드 모두에서 동일하게 작동합니다.

## 추천 경로

<Steps>
  <Step title="첫 번째 작업을 완료하세요">
[Office 문서](/docs/tutorials/office-documents)부터 시작하세요. 파일을 업로드하고 에이전트에게 보고서 작성을 요청한 후 출력을 확인하세요. 약 5분 정도 소요됩니다.
  </Step>
  <Step title="자동화된 워크플로를 사용해 보세요">
Myrm이 어떻게 무인으로 작동하는지 확인하려면 [일일 브리핑](/docs/tutorials/daily-briefing) 및 [예약 자동화](/docs/tutorials/scheduled-automation)로 이동하세요.
  </Step>
  <Step title="재사용 가능한 기술 구축">
성공적인 작업을 통해 [자신만의 스킬을 생성](/docs/tutorials/skill-creation)하는 방법을 배우면 동일한 설정을 반복하지 않아도 됩니다.
  </Step>
  <Step title="도구를 사용하여 확장">
[MCP 도구](/docs/tutorials/mcp-tools)를 통해 외부 서비스를 연결하여 에이전트에 강력한 기능을 부여하세요.
  </Step>
</Steps>

## 앞으로 나올 내용

- **고급 사례** — 다중 에이전트 협업, 워크플로 조정 및 Kanban 파이프라인
- **역할 및 산업** — HR, 영업, 마케팅, 엔지니어링 등을 위한 맞춤형 플레이북
