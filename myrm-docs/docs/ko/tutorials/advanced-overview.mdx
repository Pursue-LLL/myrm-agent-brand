# 고급 실습

이 섹션에서는 Myrm의 기능을 더욱 발전시키려는 고급 사용자를 위한 고급 패턴을 다룹니다. 튜토리얼이 활발히 개발되고 있습니다.

## 출시 예정

- **다중 에이전트 협업** — 전문 에이전트를 조직하여 팀으로서 복잡한 프로젝트를 처리합니다.
- **Kanban Pipeline** — DAG 종속성을 통해 다단계 워크플로 시각화 및 관리
- **워크플로 신뢰성** — 무인 실행되는 빌딩 자동화의 모범 사례
- **지식 기반 에이전트** — 도메인 전문 에이전트를 위한 Wiki, 메모리 및 기술 결합
