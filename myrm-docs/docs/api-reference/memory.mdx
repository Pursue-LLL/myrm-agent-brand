# Memory API

## List Memory Entries

```bash
GET /api/memory
```

## Search Memory

```bash
POST /api/memory/search
```

```json
{
  "query": "user preferences for coding style",
  "limit": 10
}
```

## Create Memory Entry

```bash
POST /api/memory
```

```json
{
  "type": "semantic",
  "content": "User prefers TypeScript with strict mode",
  "importance": 0.8
}
```

## Delete Memory Entry

```bash
DELETE /api/memory/:id
```
